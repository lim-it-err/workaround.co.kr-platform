## Goal

Create the first runnable Spring Boot gateway scaffold for the platform.

## Scope

- Set up a minimal Spring Boot application under `gateway/`.
- Add dev auth using `X-Platform-Key` for mutating endpoints.
- Add `GET /api/health`.
- Add `GET /api/services` with sample service catalog output.
- Add `GET /api/tickets` and `POST /api/tickets` with an MVP in-memory or placeholder implementation if Redis wiring is not ready yet.
- Expose Ollama health as part of the health response shape.
- Keep business logic out of the gateway.

## Acceptance Criteria

- The Spring Boot app starts locally.
- The health endpoint responds with gateway and Ollama-related state.
- The services endpoint returns a sample catalog that the frontend can consume.
- Ticket endpoints exist and have stable JSON shapes for the frontend POC.
- The implementation matches the architecture and ticket policy docs.

## Goal

Make the next version visible from a single local entrypoint at `http://localhost:7000` so the orchestrator can review all major current changes in one place.

## Scope

- Provide a local runtime entrypoint at `localhost:7000`.
- Make the frontend POC accessible through that entrypoint.
- Make the gateway-backed APIs available behind the same local preview flow.
- Ensure the current platform changes are visible from that single preview path.
- Choose an implementation that is realistic for the repo stage, such as a local reverse proxy, compose setup, or a gateway-served frontend integration.
- Document the chosen local run path clearly.

## Acceptance Criteria

- Opening `http://localhost:7000` shows the current integrated platform preview.
- The frontend station splash and main control room are reachable from that address.
- The preview can reach platform API responses required by the frontend.
- The local setup instructions are documented and reproducible.
- The implementation does not break the orchestrator and worker role split.

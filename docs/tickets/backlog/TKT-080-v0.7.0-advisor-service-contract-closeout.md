# TKT-080

## 메타데이터

- 제목: advisor 서비스 계약 마감 — /health·라우트·매니페스트·빌드 게이트
- 우선순위: P1
- 대상 버전: `v0.7.0`
- 상태: `backlog`
- 문서 상태: `작성완료`
- 진행 판정: `v0.7.0 진행 시 가능`
- 담당: codex
- scope: `services/advisor/service/**`, `services/advisor/README.md`, `infra/**`(라우트), `services/advisor/frontend/package.json`(빌드 게이트 한정)
- 의존: D-008

## 배경

advisor 는 subtree 흡수됐지만(D-008) 모선 서비스 계약에 공백이 있다 — Dockerfile 은 있으나 **`/health` 엔드포인트가 없다** (actuator 미도입, 커스텀 매핑도 없음 — 2026-08-16 확인). 또한 이 머신에서 frontend 빌드 게이트가 node 버전 비호환으로 돌지 않는다.

## 작업 내용

- `service/` 에 `/health` 추가 (spring-boot-starter-actuator 도입 또는 경량 컨트롤러 — 선택 근거 기록). 게이트웨이 헬스 집계에 등록.
- 서비스 등록 정보 문서화 (`services/advisor/README.md` 에 계약 표): 서비스 ID `advisor`, compose hostname, `/health`, 라우트 prefix `/advisor`, 환경 변수(`ADVISOR_PROFILE`·`ANTHROPIC_API_KEY`·`ADVISOR_AUTH_TOKEN`·CORS).
- 모선 compose 에 advisor 서비스 추가 (자체 `docker-compose.yml` 은 단독 개발용으로 유지, 모선 통합 기동은 모선 compose 가 담당).
- CORS 기본값(`localhost:5173`)을 같은 오리진 경로 체계(D-006)에 맞게 재검토.
- frontend 빌드 게이트 복구: node ≥20.12 상향 또는 vite 버전 고정 — **환경 요구를 README 에 명시** (AGENTS.md 검증 게이트가 어느 머신에서든 돌아야 한다).
- LLM 접근 규칙 검토: advisor 는 Anthropic API 직접 호출 구조다. 모선 정책(서비스의 Ollama 직접 의존 금지)은 외부 유료 API 에 그대로 적용되지 않으나, 키 관리·장애 격리 관점의 예외 기록을 decisions 에 남긴다.

## 완료 기준

- `GET /health` 200, 게이트웨이 집계에 advisor 상태 표시.
- 모선 compose 로 advisor 가 함께 기동된다.
- README 계약 표 완비, 빌드 게이트가 문서된 환경에서 재현 가능.
- `service/run.sh test` 그린 유지.

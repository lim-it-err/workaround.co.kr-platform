## Goal

Build the first Vue POC for the platform frontend.

## Scope

- Create a 10-second station-board splash screen inspired by Seoul subway arrival signage.
- Add a flap or ticker area with short game-style humor messages.
- Automatically transition to the main page after 10 seconds.
- Build the first main page as a station control room rather than a marketing landing page.
- Replace the generic lower scroll idea with a train-track style lower rail and moving train marker.
- Show a 2x2 or similarly compact service surface.
- Mark some services as heavy workloads that should run on another node such as `rtx5070`.

## Acceptance Criteria

- The app loads on desktop and mobile.
- The splash screen is visible first and transitions automatically after 10 seconds.
- The ticker or flap strip rotates through multiple short messages.
- The main page clearly shows service tiles and node targets.
- The lower rail uses a train motif instead of a generic footer scroll.
- The UI follows the repo frontend docs and does not look like a generic landing page.

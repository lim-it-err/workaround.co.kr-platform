## 목표

공개 Claude 대화에 담긴 여행 설계 과정과 선택지를 통합 개발 사이트의 Line V에 녹인다. 현재 화면에 이미 들어간 최종 일정은 유지하고, 아직 빠진 **왜 이 일정이 되었는지**, **예산별 선택**, **숙소 후보**, **운전·체력 리스크를 줄인 판단**을 정적 콘텐츠로 확장한다. 사용자는 이 사이트만 보고 실제 여행을 다닐 예정이므로 링크의 유의미한 내용은 요약 몇 줄이 아니라 현장에서 판단할 수 있는 수준으로 소화한다.

단순한 대화 전문 복사는 하지 않는다. 사용자가 여행 중 빠르게 훑을 수 있는 의사결정 보드와 준비 자료로 재구성한다.

- 최종 11일 일정과 날짜별 오전/오후/저녁 흐름.
- 역순안, 비엔나 선행안, 브르노 숙박안, 브르노 점심 경유안의 비교와 폐기 이유.
- 프라하·체스키크룸로프·할슈타트·잘츠부르크·바하우/멜크·비엔나·부다페스트의 체류 길이 결정.
- 잘츠부르크 공연/모차르트 디너 제외, 잘츠부르크 1박·비엔나 2박·부다페스트 2박 결정.
- 인파 회피 시간대, 카페 휴식, 어머니 동행 체력 상한과 대체 동선.
- 항공편 비교와 직항 선택 논리, 도착일 시차 적응 원칙.

- 이동 중 차량 내 짐 보안, 관리형 주차, 체크아웃 후 짐 보관과 공항 이동.
- 세체니 온천 복장·시간대·예약 등 재확인 항목.

데이터 항목마다 `current`(현재 채택), `alternative`(유효 대안), `superseded`(후속 대화로 폐기), `reverify`(운영시간·가격·정책 재확인)의 상태를 갖는다. 화면에서는 현재 채택안을 가장 먼저 보이고, 폐기안은 `왜 버렸나`에서만 접어 보여준다. 대화의 당시 추정과 `reports/2026-08-18-voyage-facts.md`의 최신 확인 결과가 다르면 최신 확인 결과를 본문으로, 당시 대화는 결정 기록으로 표시한다.

### 1. 동선 결정 기록

- 원안의 출국일 `부다페스트 → 프라하공항` 약 7시간 운전은 지연 만회 수단이 없고 운전 상한 5시간을 넘어서 폐기했다.
- 완전 역순안은 첫 운전일 `프라하 → 부다페스트`가 약 5시간 20분이라 체력 상한을 넘는 문제가 있었다.
- 비엔나 선행안은 장거리를 3시간 20분 + 2시간 40분으로 나누지만 동선이 과격하게 바뀌는 단점이 있었다.
- 최종안은 기존 여행 감각을 보존하면서 부다페스트에서 9/16 프라하로 미리 돌아오고, 출국일은 무운전으로 만든 절충안이다.
- 할슈타트는 왕복 관광이 아니라 체스키크룸로프→잘츠부르크 이동에 흡수하고, 바하우/멜크는 잘츠부르크→비엔나 이동의 휴식 지점으로 쓴다.

### 2. 예산 시나리오

- 고정비 기준: 항공 340만 원 + 렌터카 110만 원(보험 포함).
- 2인 총예산 선택지: 750 / 800 / 850만 원, 안전 상한 950만 원.
- 숙소·주차 예산과 나머지 변동비가 어떻게 달라지는지 비교한다.
- 현재 `voyage.js`의 850만 원 계획은 유지하되, 750/800안은 대안 시나리오로 표시한다.
- 가격·별점은 2026년 7월 대화 당시 추정치이며 실시간 견적처럼 보이지 않게 `당시 검토안` 라벨을 붙인다.

### 3. 도시별 숙소 후보 아카이브

- 750안: Hotel Caesar Prague / Pension Pod Skalkou / Hotel Heffterhof / Hotel Kaiserhof Wien / Benczúr Hotel / Exe City Park.
- 800안: MOSAIC HOUSE Design Hotel / Boutique Hotel Romantic / Hotel Via Roma / Lindner Am Belvedere / Mamaison Andrássy / Hotel Century Old Town.
- 850안: NH Collection Carlo IV / Hotel Bellevue / Sheraton Grand Salzburg / Radisson Blu Das Triest / Corinthia Budapest / Cosmopolitan Prague.
- 각 후보는 도시, 박수, 당시 예상가 범위, 주차·엘리베이터·대중교통·짐보관 조건, 선택 이유를 갖는다.
- 특정 호텔을 확정 예약처럼 표현하지 않는다. 외부 예약 링크·실시간 가격 조회는 범위 밖이다.

### 4. 여행 운영 판단

- 하루 주요 관광 1~2개, 카페 휴식 60~90분, 2시간마다 운전 휴식.
- 출국일 무운전, 차량은 전날 반납.
- 이동일 차내 짐 노출 최소화, 관리형 주차장·트렁크 은닉 원칙.
- 기억 대비 효율이 높은 항목은 다뉴브 소형 야경 크루즈와 비엔나 카페이며, 절약 순서는 숙소 등급→식비→입장료.

### 5. 1일차 독립 상세 세션 — 9/8 도착·회복

일정 카드 한 장의 요약으로 끝내지 않고 Line V 안에 독립적으로 열 수 있는 `1일차 상세` 세션을 둔다.

- `16:45 프라하 도착 → 입국/수하물 → 택시 → 뉴타운권 주차 가능한 숙소 → 체크인 → 가까운 곳에서 가벼운 저녁 → 수면`의 순서와 예상 소요 구간.
- 이날의 성공 조건은 관광 개수 0개가 아니라 **무리 없이 숙소에 도착하고 다음 날 컨디션을 남기는 것**이라고 명시한다.
- 야경은 기본안에서 제외한다. 컨디션이 좋을 때만 바츨라프 광장 주변 10~20분 산책, 피곤하면 즉시 취소하는 분기를 둔다.
- 공항에서 바로 확인할 항목: 수하물, eSIM/로밍, 현금·카드, 숙소 주소, 택시 승차 지점, 체크인 마감.
- 숙소 도착 후 확인할 항목: 다음 날 트램 승차 위치, 렌터카 지점/서류, 차량을 넣을 주차장 진입 방법.
- `정상`, `수하물 지연`, `입국 지연`, `어머니 피로` 네 가지 상황별 짧은 대응을 제공한다.

### 6. 2일차 독립 상세 세션 — 9/9 프라하·차량 인수·야경

Line V 안에 독립적으로 열 수 있는 `2일차 상세` 세션을 두고 시간표·이동 이유·체력 분기를 함께 제공한다.

- 08:30 트램 22로 성 위쪽 이동.
- 09:00~11:30 프라하성·성 비투스 대성당.
- 11:30~13:00 말라스트라나 방향으로 내려오며 점심.
- 13:00~14:30 조용한 카페에서 60~90분 의무 휴식.
- 14:30~16:00 카를교·구시가지. 카를교는 오래 머무는 목적지가 아니라 건너며 보는 구간으로 설명한다.
- 16:30 전후 중앙역/숙소 인근 렌터카 인수 후 숙소 지하주차장 입고.
- 17:30~19:00 휴식·저녁.
- 19:15~21:00 블타바 강변/스메타나 제방→카를교 야경 산책. 당시 검토 기준 19:30~20:00 매직아워, 20:00~20:40 완전 야경이며 실제 일몰은 출발 직전에 재확인한다.
- 피로 시 야경은 강변 30분으로 줄이고, 못 본 야경은 9/16 프라하 귀환일로 넘긴다.
- 차량 계약이 `수령 시각 이후 반납=하루 추가`인지 반드시 확인하게 한다. 유예가 없다면 `16:30 수령/8일 계약`과 `18:00 수령/7일 계약`의 비용·야경 트레이드오프를 보여주되 확정 사실처럼 쓰지 않는다.

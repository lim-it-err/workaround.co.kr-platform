# TKT-053

## 메타데이터

- 제목: 블로그 이미지 업로드와 미디어 자산 처리
- 우선순위: P2
- 대상 버전: `v0.7.0`
- 상태: `backlog`
- 문서 상태: `작성완료`
- 진행 판정: `v0.7.0 진행 시 가능`
- 소유자 유형: `worker`
- 권장 브랜치: `codex/tkt-053-blog-image-upload-media-assets`

## 목표

블로그 `Writing Studio` 에 이미지 업로드를 추가하고, 공개 글 렌더링과 연결되는 미디어 자산 저장/참조 규칙을 만든다.

## 작업 내용

- 작성 화면에 이미지 업로드 진입점을 추가한다.
- 업로드된 이미지의 저장 위치 규칙을 정한다.
- 글 본문 Markdown 에 이미지 참조를 연결하는 경로를 정한다.
- 공개 읽기 화면에서 이미지가 안정적으로 렌더링되게 한다.
- 용량 제한, 허용 포맷, 실패 메시지 기준을 정한다.
- 미디어 자산의 운영/복구 가이드를 문서화한다.

## 범위

- 포함: 업로드 UI, 저장 경로 규칙, Markdown 이미지 참조, 공개 렌더링, 운영 문서 갱신
- 제외: CDN 최적화, 이미지 편집기, 자동 리사이징 고도화, 갤러리 관리, 외부 스토리지 연동

## 완료 기준

- 작성자가 이미지 파일을 글에 넣을 수 있다.
- 업로드된 이미지가 공개 글 상세에서 안정적으로 보인다.
- 저장 위치와 운영 규칙이 문서로 남아 있다.

## 선행 조건

- `TKT-050`, `TKT-051`, `TKT-052` 가 먼저 정리되어 있어야 한다.

## 질문/결정 기록

- 결정: 이미지 업로드는 첫 블로그 버전 `v0.6.0` 에 넣지 않는다.
- 결정: 미디어 자산 처리는 블로그 읽기/쓰기 기본 흐름이 닫힌 뒤 후속으로 연다.
- 열린 질문: 파일 저장을 로컬 저장소 기준으로 둘지, 별도 미디어 경로를 둘지.

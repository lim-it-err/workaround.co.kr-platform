## Goal

Define and implement the first concrete platform path for heavy workloads and external LLM inference routing.

## Scope

- Clarify how heavy services are marked for another node.
- Define the contract between orchestrator, worker, gateway, and external Ollama runtime.
- Document how code-assist style jobs can call an external model runtime without giving that runtime direct repository control.
- Add the minimum implementation hooks needed for the gateway or worker to expose node targeting and degraded Ollama status.

## Acceptance Criteria

- The repo has a clear documented runtime contract for `rtx5070` offload.
- The frontend and gateway can both represent heavy-node targeting.
- The design keeps merge control with the user and orchestration control with the platform.
- LLM downtime behavior is explicit and testable.

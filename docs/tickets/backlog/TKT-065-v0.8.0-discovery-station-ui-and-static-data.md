# TKT-065

## 메타데이터

- 제목: 발견 정거장 UI와 정적 주제 데이터 연동 (depth 0~1)
- 우선순위: P2
- 대상 버전: `v0.8.0`
- 상태: `backlog`
- 문서 상태: `작성완료`
- 진행 판정: `v0.8.0 진행 시 가능`
- 소유자 유형: `worker`
- 권장 브랜치: `codex/tkt-065-discovery-station-ui`

## 목표

발견 노선(`Line D`)의 승강장 UI를 만들고, 미리 생성된 정적 주제 데이터(100개)를 연결해 "하루 하나 발견 + 3방향 파고들기(depth 0~1)"를 동작시킨다.

## 작업 내용

1. `frontend/src/data/discovery/topics.json`(100개, 사전 생성됨)을 로드한다. 스키마는 `docs/discovery-line-definition.md` 를 따른다.
2. 환승 홀 노선도(C 방식)에 `Line D / 발견 정거장` 지선 진입점을 추가한다.
3. 발견 정거장 페이지를 만든다.
   - 오늘의 주제를 행선판(플랩) 연출로 표시하고, `teaser`(간단 설명)를 보여준다.
   - 3선택지(`deeper` 더 깊이 / `broader` 더 넓게 / `twist` 뜻밖의 각도)를 출구 표식처럼 제시한다.
   - 선택 시 해당 `branches[key]` 텍스트(depth 1)를 보여준다.
   - depth 2~3 진입 버튼은 자리만 두고 `TKT-066`(API)에서 연결한다. 이 티켓에서는 depth 1까지만 동작.
4. 하루 하나 규칙: 날짜를 시드로 한 결정론적 선택으로 100개 중 하나를 고른다(같은 날 같은 주제). 이미 본 주제는 `localStorage` 로 추적한다.
5. "지난 발견" 목록: 지금까지 뜬 주제를 다시 볼 수 있게 한다.
6. 다크 테마 기본, 모바일 재배치를 확정된 디자인 방향(A 골격 + C 노선도)에 맞춘다.

## 범위

- 포함: 정적 데이터 로드, 발견 정거장 UI, 하루 하나 선택, depth 0~1 표시, 지난 발견 목록, 노선도 진입점.
- 제외: depth 2~3 API 확장(TKT-066), 계정 동기화, 퀴즈/정답, 주제 자동 생성.

## 완료 기준

- 발견 정거장에서 오늘의 주제와 간단 설명이 보인다.
- 3선택지를 누르면 각 방향의 depth 1 설명이 보인다.
- 날짜가 바뀌면 다른 주제가 뜨고, 지난 발견에서 이전 주제를 다시 볼 수 있다.
- `tools/run-frontend-build.ps1` 빌드가 통과한다.

## 목표

장거리 비행에서 노트북의 로컬 서버로 오래 사용할 수 있도록 Developer Advisor를 **기내 로컬 학습팩**으로 확장한다. 기존의 짧은 판단 게임을 대량 보강하고, 사건 시나리오와 서로 다른 플레이 동사를 늘린다. 단순 카드 수 복제가 아니라 도메인·난이도·사고방식의 폭을 함께 넓힌다.

## 제품 원칙

- 기내에서는 인터넷·외부 API·외부 LLM이 없다고 가정한다. 노트북의 로컬 프런트 서버는 출발 전에 기동해 둔다.
- 3분/10분/30분/60분 단위로 끊어 할 수 있어야 한다.
- 긴 코드 작성은 요구하지 않는다. 읽기·판단·순서 배치·경계 선택·가설 반증 중심이다.
- 정답 암기보다 선택의 대가와 운영 후일담을 보여준다.
- 진행 상태는 기기 로컬에 저장하고 새로고침·비행기 모드에서도 복원한다.
- 코드 제출·로컬 리뷰가 필요하면 advisor service의 mock 프로필을 함께 띄울 수 있다. 실 Claude/Ollama 리뷰는 인터넷 없는 기내 필수 흐름에서 제외한다.

## 현재 수량 기준선

- 브리핑→미션 수행→제출/리뷰로 이어지는 단독 미션: 33개.
- 독서/영화 카드: 12개.
- 머지 or 반려: 12판.
- 한 번만 물어본다면: 3판.
- 경계선 한 칸: 2판.
- 사건 파일: 2개 × 5일 = 10화.
- 현재 콘텐츠는 프런트 번들에 포함되어 로컬 서버만 켜면 인터넷 없이 읽을 수 있다.

## 정량 확장 목표 (Wave 1)

### 기존 엔진 콘텐츠

- 독서/영화 카드 `+24`개: 독서 12, 영화·다큐·실화 12.
- 머지 or 반려 `+24`판: 최종 36판.
- 한 번만 물어본다면 `+12`판: 최종 15판.
- 경계선 한 칸 `+10`판: 최종 12판.
- 사건 파일 `+6`개: 최종 8개, 총 40화.

### 신규 미니게임 3종

1. **최소 재현** — 조건을 덜어내며 버그의 최소 재현을 남긴다. 8판.
2. **둘이 동시에** — A/B 실행 순서를 끼워 넣어 경쟁 상태와 불변식 파괴를 본다. 8판.
3. **격벽 두 장** — 장애 전파 지도에서 두 연결을 차단하고 살아남은 기능·포기한 기능을 비교한다. 8판.

신규 게임 합계 24판. Wave 1 총 신규 단위는 카드/라운드/사건 기준 100개 이상으로 맞춘다(사건 파일의 각 일차는 별도 콘텐츠 단위로 센다).

### 신규 도메인 단독 미션 6개

기존 `sampleContent.js`의 33개 미션과 겹치지 않는 아래 도메인을 완성형 미션으로 추가한다. 제목만 바꾼 복제는 금지하고, 각 미션은 브리핑·요구사항·작업 자료/코드·제출·결말·해설·기획자 관점 중 기존 엔진이 지원하는 핵심 흐름을 끝까지 제공한다.

1. **백신 콜드체인 — 평균온도는 정상인데 한 번의 이탈이 있었다**: 센서 원시값, 집계값, 인계 기록이 충돌한다. 보관 적합성 판정과 chain-of-custody를 분리해 설계한다.
2. **정수장 야간근무 — 세 센서 중 둘이 서로 다르게 말한다**: 단일 센서 신뢰, 다수결, 안전 정지의 비용을 비교하고 fail-safe 경계를 정한다.
3. **박물관 국제 대여 — 작품 ID는 같지만 상태 기록은 세 벌이다**: 보존·보험·운송 시스템의 레거시 식별자와 감사 이력을 무손실로 통합한다.
4. **반도체 팹 — 격리된 웨이퍼가 다음 공정으로 흘러갔다**: MES 이벤트 순서 뒤바뀜, 품질 격리 플래그 복제, 재처리의 멱등성을 다룬다.
5. **산불 대피소 — 남은 한 자리를 두 시스템이 동시에 배정했다**: 수용량 경쟁 상태, 가족 단위 배정, 공정성·안전성·가용성의 우선순위를 다룬다.
6. **스마트 온실 — 온도 보정이 난방과 환기를 동시에 켰다**: 센서 지연, 제어 루프, 히스테리시스, 수동 개입 우선권을 다룬다.

난이도는 입문 2·중급 2·고급 2로 나누고, `코드 판독`, `설계 리뷰`, 실제 수정형을 최소 1개씩 포함한다. 실제 의료·재난 운용 지침이 아니라 합성 소프트웨어 훈련임을 콘텐츠에 표시한다.

## 오늘의 게임 + 전체 다시하기

기존 날짜 기반 `오늘의 판`은 유지하되, `/games`에 `전체 판·다시하기` 자유 플레이 모드를 추가한다.

1. 머지 or 반려, 한 번만 물어본다면, 경계선 한 칸, 카드 갈래, 사건 파일과 신규 미니게임 3종의 모든 정적 라운드를 카탈로그에서 즉시 고를 수 있다.
2. 각 게임에는 `처음부터 다시`, `다음 판`, `랜덤`, `아직 안 본 판` 진입을 제공한다. 완료한 판도 횟수 제한 없이 다시 할 수 있다.
3. 사건 파일은 날짜를 기다리지 않고 `자유 열람`에서 1~5화를 모두 열 수 있게 하되, 다음 화 제목/정답은 기본 접힘으로 스포일러를 막는다.
4. 오늘 모드와 연습 모드 상태를 분리한다. 연습 결과는 별도 이력에는 남길 수 있지만 오늘 루틴 완료·스트릭·시즌 능력치·보상은 중복 획득하지 않는다.
5. 기존 날짜 시드와 1일 1회 보호 로직은 `daily` 모드에만 유지하고, `practice` 모드는 명시적인 round ID로 재생한다.
6. 카탈로그에는 게임별 전체/완료/미완료 수와 예상 시간을 보여주고, 필터 상태·마지막 플레이 라운드를 로컬에 저장한다.
7. 날짜가 바뀌거나 새로고침해도 자유 플레이 진행은 사라지지 않는다. 개별 판의 `연습 기록 지우기`는 가능하지만 오늘 기록은 건드리지 않는다.

## 질적 확장 기준

### 도메인 분포

아래 12개 이상을 사용하고 한 도메인이 전체 신규 콘텐츠의 15%를 넘지 않게 한다.

- 항공·공항·수하물, 철도·신호, 호텔·예약, 의료·병원 운영
- 금융·송금·청산, 커머스·재고, 물류·콜드체인, 제조·품질
- 음악 공연·좌석, 제과·발효, 건축·안전, 공공행정·재난
- 데이터 파이프라인, 인증·권한, 캐시·복제, 배치·스케줄링

### 시나리오 품질

- 모든 판은 `상황 → 선택/관측 → 즉시 결과 → 시간이 지난 후의 비용 → 해설` 흐름을 갖는다.
- 문법 오류, 노골적 NPE, 프레임워크 암기만으로 풀리는 문제는 금지한다.
- 오답도 현실에서 선택할 법한 이유가 있어야 하고, 왜 여기서는 손해였는지 설명한다.
- 트레이드오프형 문제는 `정답` 대신 `이 요구사항에서의 권장`으로 쓴다.
- 동일한 코드 냄새·사고 원인을 이름만 바꿔 반복하지 않는다.
- 설명은 비개발자도 사건을 따라갈 수 있게 하고, 마지막 단락에서 기술 개념을 정확히 연결한다.
- 실제 사고를 연상시키는 내용은 특정 회사·사람을 식별하지 않는 합성 시나리오로 작성한다.

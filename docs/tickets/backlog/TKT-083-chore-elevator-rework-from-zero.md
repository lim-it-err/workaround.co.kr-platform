# TKT-083

## 메타데이터

- 제목: 엘리베이터 승강장 원점 재설계 — 표현·기능 전면 재검토
- 우선순위: P1
- 대상 버전: `chore`
- 상태: `backlog` (1단계 스펙 완료 후 `[SIM]` ready 전환)
- 문서 상태: 작성완료
- 담당: 1단계 스펙 = claude / 2단계 구현 = `[SIM]` 레인
- scope(구현 단계): `frontend/src/**` 중 엘리베이터 모듈 한정

## 배경 (PO, 2026-08-17)

> "23층 수직 승강장 — 얘도 아무것도 안 해. 표현 방식부터 원점 재검토로 다시 진행해. 디자인, 기능 모두 별로야."

현재 화면의 근본 문제: 수치 타일 + 슬라이더 + 텍스트 상태뿐이라 **아무 일도 일어나지 않는 것처럼 보인다.** 시뮬레이터인데 시뮬레이션이 안 보인다 (택시 TKT-074 와 동일 계열 — 관측성 부재).

## 진행 방식 (2단계)

1. **스펙 (claude)**: `design/` 에 재설계 문서 — ①이 시뮬의 존재 이유(핵심 루프) 재정의 ②**수직 단면 뷰**(샤프트×층 그리드에서 car 가 실제로 움직이고, 층별 대기 인원이 보이고, 호출→반응이 즉시 시각화) ③자동 수요 흐름(방치해도 살아있는 화면) ④조작부 최소화. 좌표·컴포넌트·상태 모델까지 코덱스가 추측 없이 구현 가능한 수준으로.
2. **구현 (`[SIM]`)**: 스펙 확정 후 ready 전환. 완료 게이트 = build + 다크/라이트 + 모바일 + "방치 30초 관찰 시 화면에 변화가 보인다" 체크.

## 원칙

- 원점 재검토라도 **도메인 계약은 유지** (사람 단위 모델·연속 위치·워프 금지 — feature-definition).
- 스펙 없이 구현부터 시작하지 않는다 — "뭐가 뭔지 모를 화면"의 재생산 방지.

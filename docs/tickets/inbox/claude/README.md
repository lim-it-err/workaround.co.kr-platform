# Claude 티켓 초안함

이 폴더는 Claude Code Discord Channel이 만든 티켓 초안을 받는 위치다.

Claude는 이 폴더에만 새 티켓 초안을 작성한다. Codex timer 또는 오케스트레이터가 초안을 검토하기 전까지 worker는 이 파일을 집어 작업하지 않는다.

## 파일명

```text
TKT-DRAFT-YYYYMMDD-HHMM-short-title.md
```

예:

```text
TKT-DRAFT-20260705-2130-discord-agent-bridge.md
```

## Claude가 지켜야 할 규칙

- 한 사용자 메시지에서 티켓 초안은 가능하면 하나만 만든다.
- 불확실한 내용은 `질문/결정 기록` 에 남긴다.
- 코드 구현은 하지 않는다.
- secret, token, pairing code를 본문에 적지 않는다.
- 작성 후 Discord에 파일 경로와 남은 질문만 짧게 보고한다.

## 2. 직속 지시함 — **newProject 루트 `inbox/` 로 이동** (2026-08-17, 코덱스가 루트에서 구동되므로)

PM/PO 가 특정 코덱스에게 "이거 해~"라고 찍어주는 곳. 규칙:

- **티켓 ID 포인터만** 적는다 (예: `TKT-078 — 지금 이것부터`). 업무를 직접 서술하지 않는다 — 일감의 내용·scope·게이트는 언제나 티켓 파일에 있다.
- 코덱스는 매 실행 시 자기 레인 파일을 **보드보다 먼저** 읽고, 지시가 있으면 그 티켓을 최우선으로 한다.
- 티켓 ID 가 아닌 서술이 적혀 있으면 코덱스는 **무시하고** history 에 "무효 지시" 한 줄을 남긴다 → PM 이 티켓으로 변환 후 다시 지시.
- 지정 티켓이 이미 need_review/finished 면 지시는 소화된 것 — 무시. 줄 정리는 PM 몫.

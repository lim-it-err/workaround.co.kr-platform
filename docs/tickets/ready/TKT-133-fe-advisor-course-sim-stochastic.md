## 문제
균등 간격 도착이면 이용률 100% 미만에서 대기가 항상 0 이라 학습 문항 3("임계 이용률")의 답이 100% 로 고정된다. 실제 큐는 확률 도착 때문에 70~90% 부터 대기가 커진다.

## 목표
1. 도착 간격을 **시드 고정 지수분포**(예: mulberry32 시드 + `-ln(u)/λ`)로 — 같은 조건이면 같은 결과(재현성 유지). 처리시간은 고정 유지(또는 소폭 분산, 구현자 선택).
2. 결과에 이용률과 함께 대기가 커지는 구간이 보이도록 — 11시(3.6/분)·창구 3 에서 평균 대기 > 0, 창구 1 에서 폭발.
3. `대기 중` → `시간 내 미처리`(시작 시각 > 3600초)로 의미 있게 바꾸거나 숨김.
4. 결과 설명 문구를 "시드 고정 확률 도착" 으로 갱신.

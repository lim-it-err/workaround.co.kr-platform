## 완료 조건
1. **데이터** `hallBoard.js`: 행 = { 노선(5노선: 기록·배움·놀이·생활·기지), 행선지, 상태(운행/개통 준비/샘플/공개/운행 중단), 이동 대상 page }. 시안과 같은 8행 + 순서. 기존 `lines.js` 의 page 키를 재사용. 블로그 행은 `BLOG_LINE_OPEN=false` 일 때 「운행 중단」 흐린 행(누르면 기존 블로그 닫힘 안내 토스트).
2. **기본 — 첫 방문**: 문 열림 직후 부팅 로그가 줄당 90ms(시안 문구 그대로) 흐르고 마지막 줄 뒤 500ms 에 출발 안내판으로 바뀐다. **로그 중 클릭·탭·아무 키 입력이면 즉시 안내판**(D-036 PM 권고). 재방문(스플래시의 기존 재방문 판정 재사용)·`prefers-reduced-motion` 은 로그 없이 안내판부터.
3. **기본 — 출발 안내판**: 표(노선·행선지·상태), 행 전체가 버튼/링크(≥44px), 운행 행은 해당 화면으로 이동, 「개통 준비」 행은 이동 대신 안내 문구. 노선 이름은 노선색 글자. 375 에서 가로 스크롤 0(열 3개가 들어간다).
4. **lite**: 시안 C-01 + 화살표. 제목 「환승 홀」 + 역 이름 6개(여행·Advisor·격납고·유로트럭·자취 밥상·운영 노트)만. **글자 입력 칸 없음.** `role=listbox` + `aria-activedescendant`, ↑↓ 이동(끝에서 순환), Home/End, Enter 진입. 탭/클릭: 한 번 = 선택, 선택된 줄 다시 = 진입. 선택 표시 = 반전 + `▶`. 진입 시 화면 첫 로드 때 목록에 포커스는 주지 않는다(스크린리더 첫 낭독 방해 금지), Tab 으로 들어오면 첫 항목 선택.
5. E2E(375·1440 × 기본·lite): 첫 방문 로그 → 안내판 전환, 입력으로 건너뛰기, 재방문 즉시 안내판, 행 클릭 이동, lite 키보드 ↓↓Enter 로 세 번째 역(격납고) 진입, 탭 두 번 진입, overflow 0, 영어 간판 0(브랜드명 제외). 게이트: build·unit·`e2e:all`·`git diff --check`, 캡처 4장 경로 기록.

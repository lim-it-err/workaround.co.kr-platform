## 안별 평가
- **A 순수 터미널** — 장점: 콘셉트가 가장 직관적이고 가독성·모바일 모두 안정적, 색은 노선 3색 포인트만 써서 기존 정체성이 남는다. 위험: 박스 문자는 모서리·구분선에만 쓰고 테두리는 CSS 로 그려야 한다(한글 2칸 폭 때문). 글꼴 폴백에 따라 격자 느낌이 기기마다 다르다. 난이도: 낮음~중(공용 박스·행 컴포넌트 3개로 전 화면 커버).
- **B 레트로 역 안내판** — 장점: 지하철 정체성을 가장 많이 유지하고 한글 폭 함정이 거의 없다(박스 문자 미사용). 노선색 머리띠로 위계가 분명. 위험: "코드창" 느낌은 약해 PO 의도(`-` `|` 터미널)에서 가장 멀다. 난이도: 낮음(현 토큰 + 어두운 면).
- **C CRT** — 장점: 분위기 최강, 이중선으로 박스 느낌. 위험: 스캔라인·비네트 오버레이가 가독성·성능(저사양 모바일)·장시간 읽기 피로에 불리, 단색 인광은 노선색 구분을 잃는다(노선 3색이 사라짐). 난이도: 중(오버레이·모션 감소 대응·대비 검증).
- [반박] 한글 고정폭은 글꼴 폴백에 따라 폭이 달라 텍스트 박스를 쓸 수 없다. 모든 안이 CSS 격자를 쓴다. 진짜 글자 격자를 원하면 웹폰트 결정 필요. 상세는 `design/mockups-v0.9/index.html`.

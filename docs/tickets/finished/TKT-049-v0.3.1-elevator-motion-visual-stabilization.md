# TKT-049

## 메타데이터

- 제목: 엘리베이터 floor warp 완화와 가변 car 수/승객 애니메이션
- 우선순위: P1
- 대상 버전: `v0.3.1`
- 상태: `finished`
- 문서 상태: `작성완료`
- 진행 판정: `진행 가능`
- 소유자 유형: `worker`
- 권장 브랜치: `codex/tkt-049-elevator-motion-visual-stabilization`

## 목표

현재 엘리베이터 시뮬레이터에서 간헐적으로 보이는 층간 warp 움직임을 완화하고, 엘리베이터 대수를 사용자가 조절할 수 있게 하며, car 내부 승객 수가 더 직관적으로 읽히는 시각 표현을 추가한다.

## 작업 내용

- `services/elevator-service/app.py` 와 `frontend/src/App.vue` 의 현재 이동/갱신 cadence 를 함께 점검한다.
- 같은 시각 프레임에서 car 가 여러 층을 점프한 것처럼 보이는 원인이 서비스 tick 인지, 프런트 poll/render 인지 구분한다.
- 서비스 쪽 원인이면 `position`, `currentFloor`, 목표층 갱신 규칙을 조정해 다층 점프를 줄인다.
- 프런트 쪽 원인이면 마지막 상태와 새 상태 사이를 자연스럽게 보간해 층간 이동이 한 칸씩 흘러가듯 보이게 한다.
- 수요 제어 패널에 엘리베이터 대수 조절 UI 를 추가한다.
- 기본 엘리베이터 수는 4대로 유지하되, 2대 이상 6대 이하 범위에서 조절 가능하게 하는 것을 기본안으로 둔다.
- car 내부 승객 수를 숫자만이 아니라 점, 바, 실루엣 같은 간단한 애니메이션 표현으로 함께 보여준다.
- 탑승/하차 시 load 변화가 즉시 읽히도록 micro animation 또는 상태 전환 표현을 추가한다.
- 관련 문서와 히스토리를 갱신한다.

## 범위

- 포함: 이동 안정화, 렌더 보간 또는 cadence 조정, 가변 car 수 제어, 승객 수 시각화, 문서 갱신
- 제외: 엘리베이터 알고리즘 전면 재작성, 멀티빌딩 시뮬레이션, 3D 그래픽, 택시 시뮬레이터 작업

## 완료 기준

- 사용자가 floor warp 를 쉽게 느끼지 않을 정도로 car 이동이 자연스럽게 보인다.
- 엘리베이터 대수를 UI 에서 조절할 수 있다.
- car 내부 승객 수가 숫자 외 시각 표현으로도 읽힌다.
- 기존 수요 프리셋, 수동 승객 추가, 목적층 기반 모델이 회귀하지 않는다.
- `frontend` build 와 `elevator-service` smoke 또는 동등한 검증 결과가 남는다.

## 선행 조건

- `TKT-035` 의 승객 단위 상태와 연속 위치 baseline 을 기준으로 삼는다.
- 현재 `localhost:7000` 통합 프리뷰가 재현 가능해야 한다.

## 질문/결정 기록

- 결정: 이 티켓은 새로운 배차 규칙보다 움직임 안정화와 시각 가독성 개선에 집중한다.
- 결정: 엘리베이터 대수 조절은 2~6대 범위를 기본안으로 둔다.
- 결정: 승객 수 표현은 간단한 2D 애니메이션으로 시작하고, sprite 기반 사람 캐릭터까지는 요구하지 않는다.
- 결정: warp 완화는 서비스와 프런트 중 한쪽만 고치고 끝내지 말고, 원인을 분리해 필요한 층에서 함께 보정한다.
- 결정: car 수 변경 시 초기 배치는 1차 구현에서 고정 분산으로 둔다.
- 결정: 수요 분포는 시간대별 프리셋을 기본으로 둔다.
  - 출근 시간대는 1층 승객 유입을 더 크게 둔다.
  - 식사 시간대는 2층, 3층 수요를 더 크게 둔다.
  - 저녁 시간대는 4층 수요를 더 크게 둔다.
- 제외: 수요 예측 기반 동적 재배치와 복잡한 time-series 최적화는 이번 티켓에 넣지 않는다.

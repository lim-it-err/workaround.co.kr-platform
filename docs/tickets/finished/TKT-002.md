# TKT-002

- status: finished
- priority: P1
- version: v0.1.0
- title: Spring Boot 게이트웨이 스캐폴드 및 플랫폼 API
- branch: `codex/v0.1.0-worker-node`

## 요약

Spring Boot 게이트웨이 스캐폴드가 추가되었고, 헬스, 서비스 메타데이터, 티켓 생성, 티켓 수명주기 전환 API가 구현되었다. `v0.1.0` 종료 기준에서는 필요한 골격이 갖춰진 것으로 본다.

## 변경 내용

- 게이트웨이 애플리케이션 엔트리포인트를 추가했다.
- `/api/health`, `/api/services`, `/api/tickets`, `/api/tickets/{id}` API를 추가했다.
- `v0.1.0` 루프를 위한 티켓 생성 및 워커 수명주기 엔드포인트를 추가했다.
- 프런트엔드에 바로 데이터가 보이도록 기본 티켓과 샘플 서비스 descriptor를 넣었다.
- 비HTTP worker descriptor가 전체 헬스를 강제로 degraded 시키지 않도록 health aggregation을 보정했다.

## 검증

- 구현 코드를 `docs/ticket-policy.md`, `docs/network.md` 와 대조 검토했다.
- 변경성 엔드포인트가 `X-Platform-Key` 를 요구하도록 맞춘 것을 확인했다.
- 비HTTP worker descriptor를 `skipped` 로 처리하는 보정이 코드에 반영된 것을 확인했다.

## 리뷰 메모

- 현재 오케스트레이터 환경에는 `java`, `node`, `python`, `docker` 가 PATH에 없어서 로컬 재실행 검증은 하지 못했다.
- 다만 worker handoff 내용, 정적 코드 검토, 워커 쪽 후속 smoke 근거를 종합했을 때 `v0.1.0` 종료 기준의 게이트웨이 골격은 충족한다고 판단한다.

## 후속 메모

- 전체 실행 재검증과 빌드 툴 정리는 `v0.1.1` 및 `v0.1.2` 단계에서 이어간다.

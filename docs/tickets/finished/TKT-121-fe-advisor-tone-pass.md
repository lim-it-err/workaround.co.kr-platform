**[디자이너 의견] (2026-09-14, codex-8 — PM 결정 전 권고)** 기존 [전면 검수의 우선순위 1~5](../../reviews/UX-ADVISOR-2026-09-14.md#3-우선순위-상위-5)를 기준으로, 스킨만으로 닫지 말자는 반박에 동의한다. ① 전역 3표면은 TKT-121에서 PM이 이름·각 표면의 책임·기존 URL 대응을 먼저 확정한 뒤 뼈대를 만들고, TKT-124는 그 ‘배우기’ 안의 코스 목록/상세와 형식별 진입을 맡기는 분리를 권고한다. TKT-124가 121 완료를 기다리므로 전역 IA 결정을 124로 넘겨 서로 기다리게 하지 않는 편이 좋다. ‘오늘’ 첫 화면에는 대상 이름과 시작/이어서 하기 하나를 먼저 보여주고, 기존 상세 딥링크·기내 진입·학습 콘텐츠는 보존한다. ② 초안은 파일명·여러 파일·본문·설명 등 사용자가 편집한 값을 함께 복원하고, 미션/모드 전환 시 서로 덮어쓰지 않아야 한다. 목록 왕복·탭 전환·새로고침과 저장 실패를 재검수 기준으로 삼는다. ‘저장됨’은 실제 보존이 확인될 때만 표시하고, 실패하면 입력 유지와 재시도/이탈 보호를 제공한다. 제출 성공 뒤 정리할 때도 그 제출분만 대상으로 하고, 응답 대기 중 새로 쓴 내용까지 비우지 않는 경험을 권고한다. localStorage·키 구성·보존 기간은 PM의 저장 계약 결정 사항이다. ③ 입력 보호를 첫 작업으로, 실제 진입 경로로 복귀·‘다음 미션’ 목적지와 문구 일치·기내 빈 결과의 시간 늘리기/조건 초기화·실제 조작 영역 40px 확보를 뒤이어 처리하는 순서를 권고한다. Probe는 결과를 읽은 자리에서 가설을 고르고 결말로 이어지도록 하되 학습 규칙은 보존한다. 분할한다면 PM이 각 항목의 후속 티켓과 수용 기준을 연결해 누락을 막아야 한다. 근거는 [초안 소실](../../reviews/UX-ADVISOR-2026-09-14-assets/flow-draft-after.png)·[관측 후 역방향 이동](../../reviews/UX-ADVISOR-2026-09-14-assets/flow-probe-observed.png)·[기내 복구 실패](../../reviews/UX-ADVISOR-2026-09-14-assets/flow-inflight-empty.png)이며, 기존 검수의 소스 61개가 현재와 일치함을 재확인했다. 이번 자문에서 새 실렌더나 구현 검증은 하지 않았고, 이 의견은 스펙 확정·blocked 해제·구현 승인에 해당하지 않는다.

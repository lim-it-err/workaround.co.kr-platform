## 메타데이터

- 제목: 플랩 안내 방송 문구 확장과 랜덤 로테이션

- 대상 버전: `v0.4.0`
- 상태: `finished`
- 문서 상태: `작성완료`
- 진행 판정: `진행 가능`
- 소유자 유형: `orchestrator`
- 권장 브랜치: `codex/tkt-046-flap-copy-rotation`

## 목표

첫 splash 화면의 안내 방송 문구를 더 풍부하고 기억에 남는 톤으로 확장하고, 문구 노출을 랜덤화해 화면이 매번 조금씩 다른 생활감과 유머를 전달하게 만든다.

## 작업 내용

- `frontend/src/App.vue` 의 `tickerLines` 문구 풀을 대폭 확장한다.
- 문구는 도시 생활, 사회적 배려, 피로, 자기풍자, 가벼운 블랙유머를 섞은 한국어 톤으로 정리한다.
- 사용자가 직접 허용한 고정 문구 `관리자 몰래 내맘대로 홈페이지 로딩하는 중` 을 포함한다.
- 기존 순차 회전 대신, 같은 문구가 바로 반복되지 않는 랜덤 deck 회전 로직을 추가한다.
- 관련 UX 문서와 로드맵, 보드, 히스토리를 함께 갱신한다.

## 범위

- 포함: splash ticker copy, ticker rotation logic, frontend UX 문서, roadmap, 티켓 보드, 히스토리 기록
- 제외: Work Manager 로직, elevator dispatch 로직, gateway API, `VERSION` 승격, 릴리스 승인

## 완료 기준

- splash 안내 방송 문구 풀이 기존보다 명확히 늘어나 있다.
- 같은 문구가 연속해서 반복되지 않는다.
- 문구 톤이 생활 유머, 사회적 감각, 약간의 장난기를 함께 전달한다.
- `frontend` build 검증이 통과한다.
- 관련 문서와 티켓 기록이 저장소 상태와 일치한다.

- 결정: 사용자가 직접 추가를 지정한 `관리자 몰래 내맘대로 홈페이지 로딩하는 중` 은 그대로 포함한다.

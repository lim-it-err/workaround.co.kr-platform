# TKT-017

## 메타데이터

- 제목: 로드맵 결정 질문 수집과 1차 목표 확정
- 우선순위: P1
- 대상 버전: `chore`
- 상태: `finished`
- 문서 상태: `작성완료`
- 소유자 유형: `orchestrator`
- 권장 브랜치: `codex/tkt-017-roadmap-decision-record`

## 목표

로드맵 관련 핵심 결정을 문서로 고정하고, `workaround.co.kr` / `workaround.kr` 1차 목표 이후의 개발 흐름을 명확하게 정리한다.

## 작업 내용

- `docs/roadmap.md` 의 질문과 결정 영역을 기준으로 핵심 방향을 정리했다.
- 첫 공개 웹사이트와 로컬 `v0.2.0` 프리뷰의 역할을 분리했다.
- `workaround.co.kr` 을 대표 도메인, `workaround.kr` 을 리다이렉트 도메인으로 정리했다.
- `v0.2.0` 이후에는 `v0.3.0` 을 다음 minor 후보로 보는 기준을 확정했다.
- 엘리베이터 시뮬레이터 본 구현은 `v0.2.0` 이후로 넘겼다.

## 범위

- 공개 사이트 방향, canonical domain, 첫 화면, 호스팅 방식, `v0.2.0` 이후 상한을 정리한다.
- `docs/roadmap.md`, `docs/steering.md`, `docs/version-policy.md`, `docs/tickets/board.md` 가 같은 결론을 바라보게 맞춘다.
- 결론이 나지 않은 부분은 열린 질문으로 남긴다.

## 완료 기준

- `docs/roadmap.md` 에 현재 결정과 열린 질문이 분리되어 있다.
- 보드의 우선순위와 로드맵이 충돌하지 않는다.
- `v0.2.0` 이후의 후보가 문서에 명시되어 있다.
- 남은 질문이 어디에 있는지 문서만 읽어도 알 수 있다.

## 작업자 산출물

- 로드맵 결정 요약
- 문서 갱신 목록
- 남은 열린 질문
- 보드 반영 여부

## 검토 메모

- `workaround.co.kr` 을 대표 도메인으로 두고, `workaround.kr` 은 리다이렉트 도메인으로 둔다.
- `v0.2.0` 은 로컬 통합 프리뷰와 서비스 정리의 목표 버전이다.
- `v0.3.0` 은 `v0.2.0` 이후의 다음 minor 후보다.
- 엘리베이터 시뮬레이터는 `v0.2.0` 이후 후보로 분리했다.

## Notes

- 이 티켓은 오케스트레이터가 직접 처리하는 문서/정책 티켓이다.
- 남은 질문은 `docs/roadmap.md` 의 열린 질문에 유지한다.

# TKT-013

## 메타데이터

- 제목: 문서 한국어 통일과 티켓 흐름 정리
- 우선순위: P2
- 대상 버전: `chore`
- 상태: `finished`
- 문서 상태: `작성완료`
- 소유자 유형: `worker`
- 권장 브랜치: `codex/tkt-013-docs-korean-ticket-flow`

## 목표

핵심 운영 문서와 티켓 흐름을 한국어 기준으로 맞추고, 작업자와 오케스트레이터가 같은 표현을 쓰도록 정리한다.

## 작업 내용

- 핵심 문서와 백로그 티켓에서 용어가 서로 다른 부분을 정리했다.
- 티켓 형식에 `작업 내용` 과 `질문/결정 기록` 이 반영되어 있는지 확인했다.
- 한국어 문서 표현이 깨지거나 과하게 중복된 부분을 정리했다.
- `docs/tickets/board.md` 와 실제 티켓 상태가 맞는지 검토했다.
- 문서 정리 중 새로 드러난 후속 과제는 Notes 또는 별도 티켓 후보로 분리했다.

## 범위

- 핵심 운영 문서와 백로그 티켓의 표현을 한국어 기준으로 맞춘다.
- 릴리스 목표, 티켓 정책, 보드 표현이 같은 흐름과 같은 용어를 쓰도록 정리한다.
- 티켓의 메타데이터, 목표, 범위, 완료 기준, 산출물, 검토 메모 형식을 통일한다.

## 완료 기준

- 대상 문서가 한국어로 정리되어 있다.
- 티켓 흐름 표현이 문서마다 충돌하지 않는다.
- 작업자가 문서만 읽어도 버전 목표와 티켓 이동 흐름을 이해할 수 있다.
- 후속 문서 정리 대상이 따로 기록되어 있다.

## 작업자 산출물

- 브랜치 이름
- 정리한 문서 목록
- 용어 정리 요약
- 검토 방식
- 남은 후속 과제

## 검토 메모

- 핵심 운영 문서와 티켓 문구를 현재 기준으로 맞췄다.
- `started` / `need_review` / `finished` 흐름과 보드 표기가 일관되게 보이도록 정리했다.
- 남은 영어 표현이나 세부 문장 정리는 별도 chore 티켓으로 분리할 수 있다.

## Notes

- 이 티켓은 문서 표현 정리 자체가 목표라, 기능 변경은 포함하지 않는다.
- 후속으로 더 광범위한 언어 정리나 섹션 재배치는 별도 티켓으로 빼는 편이 낫다.

# TKT-003

- status: finished
- priority: P2
- version: v0.1.0
- title: 워커 흐름, 샘플 서비스 연결, 로컬 테스트 루프
- branch: `codex/v0.1.0-worker-node`

## 요약

작은 Python 워커 루프가 추가되었고, 게이트웨이에서 queued 티켓을 가져와 샘플 서비스 상태를 점검한 뒤 티켓을 완료하는 기본 흐름이 마련되었다. `v0.1.0` 종료 기준의 첫 워커 루프는 충족한 것으로 본다.

## 변경 내용

- `ion2-worker` Python 워커 스캐폴드를 추가했다.
- 게이트웨이 API와 연결해 claim / complete / fail 흐름을 구현했다.
- 샘플 Python 서비스와 샘플 Spring 서비스의 health / ping 경로를 정리했다.
- 로컬 서비스 포트와 워커 런타임 계약을 문서화했다.
- mock gateway와 두 개의 mock health endpoint를 이용해 queued 티켓이 `completed` 로 가는 smoke 근거를 남겼다.

## 검증

- 워커가 게이트웨이 서비스 메타데이터와 health endpoint를 참조하는 구조를 확인했다.
- 샘플 서비스가 프런트엔드 없이도 독립 점검 가능하게 유지된 점을 확인했다.
- handoff 문서에 sample ticket completion smoke 근거가 포함된 것을 확인했다.

## 리뷰 메모

- 현재 오케스트레이터 환경에는 `python`, `java`, `docker` 가 없어 전체 로컬 통합 재실행은 하지 못했다.
- 다만 worker handoff와 코드 경로, smoke 근거를 종합했을 때 `v0.1.0` 종료 기준의 첫 워커 루프는 충족한다고 판단한다.

## 후속 메모

- 실제 `localhost:7000` 통합 프리뷰 기준의 end-to-end 검증은 `v0.2.0` 단계에서 다시 본다.

## 구현 내역

- `lines.js`의 기록선·기지선·실험선을 D-015/r16 좌표의 직선으로 교체했다. 기록선과 기지선은 허브를 관통하는 단일 경로, 실험선은 같은 직선 위의 북동 실선·남서 예정 점선으로 구성하고 큰 역·작은 역·이름·노선명 좌표를 목업과 일치시켰다.
- SVG `viewBox`를 r16 좌표계인 `0 0 720 720`으로 바꾸고, 노선 전체 → 작은 역 전체 → 큰 역 전체 → 허브 순서로 렌더링해 교차점과 역 테두리가 선 위에 또렷하게 남도록 했다. 순환선 C 심볼 경로와 허브 링은 보존하고 이름만 `(360,306)`으로 옮겼다.
- 모바일에서는 작은 역을 숨기고 큰 역 8개 이름을 모두 24px, 노선명은 18px로 표시했다. 기존 3묶음 목록, 6개 대표 진입, V의 단일 `노선도` 서브링크, Advisor 딥링크와 키보드 이동 계약은 유지했다.
- unit에 점-직선 거리 검사를 추가했고, E2E는 375/1440 × 다크/라이트 네 조합에서 글자 bbox 상호 겹침과 3px 간격 경로 샘플의 글자 bbox 침범을 자동 검사하도록 확장했다.

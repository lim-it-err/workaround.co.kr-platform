# TKT-061

## 메타데이터

- 제목: Work Manager 인증 세션 UX (401/만료 시 게이트 재잠금)
- 우선순위: P1
- 대상 버전: `v0.4.1`
- 상태: `finished`
- 문서 상태: `작성완료`
- 진행 판정: `진행 가능`
- 소유자 유형: `worker`
- 권장 브랜치: `codex/tkt-061-work-manager-auth-session-ux`

## 목표

세션 토큰 만료/401 을 프론트엔드가 감지해 command gate 를 다시 잠그고, "잠금 해제됨"으로 보이지만 모든 액션이 401 로 실패하는 사용자 체감 오작동을 제거한다.

## 작업 내용

1. [사용자 체감 "잘못 동작" 의 가장 유력한 직접 원인] 401/만료 시 토큰 미정리 (#6)
   - 토큰 저장: `frontend/src/App.vue:1581`; localStorage 영속화 `:1069-1079`; 로드 복원 `:232`, `:2360-2364`.
   - `saveWorkTicketMetadata` 의 catch(`frontend/src/App.vue:1625-1627`)와 `submitPresetCommand` 의 catch(`:1662-1664`)가 401 을 그대로 삼키고 토큰을 지우지 않는다.
   - 서버는 세션 만료 시 401 을 반환한다(`gateway/src/main/java/com/workaround/platform/gateway/PlatformGatewayApplication.java:534-537`).
   - 클라이언트가 auth 응답의 `expiresAt`/`sessionTtlMinutes` 를 저장/사용하지 않고 무시한다.
   - 증상: 30분 TTL 이 지난 뒤에도 잠금 해제 배너(`frontend/src/App.vue:3824`)와 상세 패널 잠금 표시(`:4097-4098`)가 "unlocked" 로 남고, 버튼이 활성 상태로 보이며, 모든 요청이 401 로 실패하는데 아무 신호가 없다. 하루 지난 localStorage 토큰도 로드 시 unlocked 로 보인다.
   - 수정 방향:
     - (a) 인증이 필요한 모든 요청의 catch 에서 401 을 감지하면 토큰과 localStorage 를 지우고 게이트를 잠금 상태로 되돌린다.
     - (b) auth 응답의 `expiresAt` 를 저장하고, 만료 시각 도달 전에 사전 잠금한다(타이머 또는 요청 전 만료 검사).
     - (c) 로드 복원 시 저장된 `expiresAt` 가 이미 지났으면 토큰을 복원하지 않고 잠금 상태로 시작한다.

## 범위

- 포함: `App.vue` 인증 상태/게이트 UI, 토큰 저장·복원·만료 처리, 401 공통 처리
- 제외: 게이트웨이 토큰 유출 근본 수정(TKT-060), 전이 흐름(TKT-062), 저장소 정합(TKT-063), 동시성/테스트(TKT-064)

## 완료 기준

- 서버가 401 을 반환하면 UI 가 즉시 잠금으로 전환되고 배너/상세 패널이 "잠금" 을 표시한다. (런타임 체크: stale-token UX 해소)
- 저장된 `expiresAt` 가 지난 상태로 페이지를 로드하면 게이트가 잠금으로 시작한다.
- TTL 경과 후 실행성 액션 버튼이 비활성/재인증 유도 상태가 된다.
- 사용자가 재인증하면 정상 동작이 복구된다.

## 작업자 산출물

- 브랜치 이름: `codex/v0.6.0-line` (공유 작업 트리, commit 없음)
- 401/만료 처리 흐름: `fetchJson` 오류에 HTTP status 를 보존하고, 메타데이터 저장·preset command 가 401 을 받으면 공통 재잠금 함수에서 메모리 토큰과 저장소 값을 함께 제거한다.
- `expiresAt` 저장·사전 잠금: 인증 응답의 `expiresAt` 를 토큰과 별도 저장하고 정확한 남은 시간으로 타이머를 예약한다. 요청 직전에도 만료를 재검사하며, 페이지 복원 시 만료됐거나 만료 정보가 없는 기존 토큰은 복원하지 않는다.
- 실행성 UI: 재잠금 뒤 메타데이터 저장과 preset command 전송 버튼이 모두 비활성화되고 재인증 안내를 노출한다.

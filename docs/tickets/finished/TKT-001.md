- branch: `codex/v0.1.0-worker-node`

## 요약

현재 Vue 프런트엔드는 `docs/frontend-ux.md` 에서 요구한 역 안내판 스플래시, 관제실 메인 셸, 서비스 타일, 헬스 뷰, 최근 티켓 목록 방향을 이미 충족한다. `v0.1.0` 범위에서는 구현이 완료된 것으로 본다.

## 변경 내용

- 기존 splash 화면, flap strip, route map, 반응형 관제실 레이아웃을 `v0.1.0` 기준 구현으로 유지했다.
- 프런트엔드는 계속 게이트웨이 `/api` 프록시 경로를 사용한다.

## 검증

- 현재 UI를 `docs/frontend-ux.md` 와 대조 검토했다.
- 스플래시 화면과 메인 관제실 POC 목표를 충족하는 것을 확인했다.

## 후속 메모

- 추후 `chore` 티켓이나 후속 버전에서 UI polish, 개발용 패널, 세부 상호작용은 추가로 다듬을 수 있다.

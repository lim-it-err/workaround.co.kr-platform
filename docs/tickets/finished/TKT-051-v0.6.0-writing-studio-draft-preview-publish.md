# TKT-051

## 메타데이터

- 제목: 글쓰기 스튜디오와 초안/미리보기/발행 흐름
- 우선순위: P1
- 대상 버전: `v0.6.0`
- 상태: `finished`
- 문서 상태: `작성완료`
- 진행 판정: `v0.6.0 진행 시 가능`
- 소유자 유형: `worker`
- 권장 브랜치: `codex/tkt-051-writing-studio-draft-preview-publish`

## 목표

단일 작성자가 글을 쓰고, 초안으로 저장하고, 미리보고, 발행할 수 있는 `Writing Studio` 를 만든다.

## 작업 내용

- 작성자용 글쓰기 화면을 만든다.
- 제목, slug, 요약, 본문 Markdown 편집 UI 를 만든다.
- 편집기와 미리보기 구조를 만든다.
- 상태 전환 `draft`, `published`, `archived` 를 다룬다.
- 임시 저장 또는 마지막 저장 시각을 표시한다.
- 공개 아카이브와 어떤 상태만 연결되는지 명확히 구분한다.

## 범위

- 포함: 작성 화면, Markdown 편집, preview, 상태 전이, 저장 상태 표시, 관련 문서 갱신
- 제외: 다중 작성자 협업, rich text editor, 이미지 업로드 고도화, 외부 인증

## 완료 기준

- 새 글을 만들 수 있다.
- 초안 저장과 미리보기가 가능하다.
- 발행 상태와 비공개 상태가 구분된다.
- 발행된 글만 공개 아카이브에 노출된다.

## 선행 조건

- `TKT-050` 의 공개 읽기 구조와 충돌하지 않아야 한다.
- `docs/blog-writing-space-definition.md` 의 콘텐츠 모델을 따른다.

## 질문/결정 기록

- 결정: 첫 버전은 Markdown 우선이다.
- 결정: 첫 버전은 단일 작성자다.
- 결정: rich text 보다 편집 + preview 이중 구조를 우선한다.
- 결정: slug 는 제목 기반 자동 생성을 기본으로 두되, 작성자가 수동 수정할 수 있게 한다.
- 결정: `Writing Studio` 는 공개 읽기 화면과 다른 리듬을 가져야 하며, 편집 집중 레이어와 상태 관리 레이어를 분리한다.

# TKT-050

## 메타데이터

- 제목: 블로그 허브와 공개 글 아카이브/상세 라우팅
- 우선순위: P1
- 대상 버전: `v0.6.0`
- 상태: `finished`
- 문서 상태: `작성완료`
- 진행 판정: `v0.6.0 진행 시 가능`
- 소유자 유형: `worker`
- 권장 브랜치: `codex/tkt-050-blog-hub-public-archive`

## 목표

포털 안에 `Blog District` 진입점을 만들고, 공개 글 목록과 글 상세 읽기 페이지까지 이어지는 기본 읽기 라우팅을 연다.

## 작업 내용

- 메인 허브 또는 후속 허브에 `Blog District` 진입 카드를 추가한다.
- 공개 글 목록 페이지를 만든다.
- 글 상세 읽기 페이지를 만든다.
- 기본 라우팅 구조를 정한다.
  - 예: `blog`, `blog-archive`, `blog-post`
- 공개 읽기 화면이 시뮬레이터 화면과 다른 리듬으로 읽히도록 레이아웃을 분리한다.
- 글 데이터가 아직 일부만 준비돼 있어도 placeholder 또는 seed data 로 읽기 흐름을 검증 가능하게 만든다.

## 범위

- 포함: 허브 진입 카드, 공개 아카이브, 글 상세 읽기, seed 데이터 기반 라우팅, 관련 문서 갱신
- 제외: 글 편집기, 발행 액션, 다중 작성자 권한, 댓글, 검색, 구독

## 완료 기준

- 포털에서 `Blog District` 진입점을 볼 수 있다.
- 공개 글 목록과 상세 읽기가 이어진다.
- 긴 글 읽기 화면이 시뮬레이터 화면과 다른 레이아웃 리듬을 가진다.
- production build 또는 동등한 검증이 성공한다.

## 선행 조건

- `docs/blog-writing-space-definition.md` 를 기준으로 삼는다.
- 관련 디자인 브리프가 있으면 함께 읽는다.

- 결정: 첫 버전은 단일 작성자 기준의 공개 아카이브다.
- 결정: 댓글, 좋아요, 검색은 이번 티켓에 넣지 않는다.
- 결정: `Blog District` 는 메인 허브에 직접 진입 카드로 둔다.
- 결정: 공개 아카이브와 글 상세는 `design/blog-district-ui-system-2026-06-26.md` 의 읽기 리듬 기준을 따른다.

## 구현 내역
- `lines.js`의 W·R에 `access: 'protected'`, D·P에 `access: 'planned'`를 두어 화면 표현과 차단 동작이 같은 데이터 계약을 사용하게 했다. 기존 W/R `page`와 직접 라우팅 계약은 바꾸지 않았다.
- SVG 역과 목록 행을 모두 키보드 조작 가능한 버튼으로 연결했다. 클릭·Enter·Space 시 주소를 유지한 채 `보호 구역 · 준비 중` 또는 `예정 노선 · 준비 중` 토스트 하나만 표시하고, 재입력 시 2.5초 타이머를 다시 시작한다.
- 데스크톱 토스트는 누른 요소 바로 아래, 모바일은 안전 영역을 고려한 하단 한 줄로 배치했다. `role="status"`, `aria-live="polite"`, 포커스 표시를 포함한다.
- 기지선 전체와 D·P 점선·역·목록을 흐리되 숨기지 않았다. 다크는 55%, 라이트는 질문 기록의 대비 해법에 따라 80%를 사용한다.
- 공유 파일: `frontend/src/styles.css`(TKT-138 미커밋 hit-area 변경 보존), `docs/tickets/board.md`, `docs/history/2026-09-15.md`.

## 변경과 근거

- 우측 도구는 사진 첨부·H1/H2/H3·표 삽입 **세 조작부**만 남겼다. 미니 표와 행/열 조립 메뉴는 제거했다 (`writing-studio.html:57`, `:59`).
- 텍스트→본문 표→이어 쓰는 텍스트 순서로 구성했다. 표에는 셀 입력, 오른쪽 +열, 아래 +행, 셀 ⋯를 둬 hover/focus 때의 편집 위치를 정적으로 보여준다 (`:47`~`:54`). 내부 참조 토큰·Markdown 파이프 노출 없음.
- CSS `:target`으로 모바일 도구 열기/닫기, 도구의 표 삽입→본문 표 위치, 셀 메뉴 열기/닫기를 연결했다 (`:24`, `:29`). 블로그 복귀는 기존 목업으로 연결한다.
- 실제 눌림 영역을 버튼 44px 이상, 셀 메뉴 40px 이상으로 정합했다 (`:16`, `:24`). 다크 발행 버튼 글자 대비와 라이트 실토큰도 보정했다. 본문은 데스크톱 정중앙 720px을 유지한다.

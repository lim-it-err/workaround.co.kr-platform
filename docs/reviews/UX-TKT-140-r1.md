## [제안] S1 — 재방문 플랩의 읽기 시간을 조금 확보하기

3초 재방문에서 회전 연출이 대부분의 시간을 사용한다. 40ms 간격으로 실제 CSS animation 상태와 현재 보이는 아래 반쪽을 함께 추적한 4회에서, **DOORS OPENING이 정착한 시점은 약2.60~2.68초**였다. 3초 전환 시작 전 안정적으로 읽는 시간은 약0.32~0.40초다. 문구는 완성됐고 페이지도 정상 전환하므로 블로커나 중요 결함은 아니다.

- 화면: [375 다크 마지막 구간](UX-TKT-140-r1-assets/visual-end-0-375-dark.png), [1440 라이트](UX-TKT-140-r1-assets/visual-end-3-1440-light.png). 실측: [visual-settle.json](UX-TKT-140-r1-assets/visual-settle.json).
- 파일: `frontend/src/App.vue:1413` 무작위 회전 횟수, `:1447`~1477 반쪽 회전/정착, `:1485`~1500 글자별 지연, `:2348` 전환 타이머.
- 제안: 재방문 총3초와 기존 반쪽 플랩 표현은 유지하되 재방문 회전 횟수·시차만 줄여 마지막 문구의 읽기 시간을 더 확보할 수 있다. 목표 시간·적용 여부는 PM이 결정한다.

**측정 해석 정정:** 처음 수집한 `settle.json`은 Vue의 static 아래 반쪽과 `.run` class만 보아 8회 중3회에서 종료 전 내부 정착을 못 찾았다. CSS `forwards`로 최종 동적 반쪽이 이미 보일 수 있으므로 이는 ‘글자가 덜 완성된 채 종료’의 충분한 증거가 아니다. `visual-settle.json`에서 실제 애니메이션 종료와 동적 아래 반쪽까지 확인했고, 그4회는 모두 완성됐다. 이 차이를 제품 결함으로 보고하지 않는다. 무작위 연출의 전수 보증을 뜻하지도 않는다.

## 공통 체크리스트

- **주인공·면:** 사이트명·플랩으로 시선이 모이고 패널 면 제거가 확인된다. 플랩보드와 배경 정체성은 승인된 유지 대상이다.

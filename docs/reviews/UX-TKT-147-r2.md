## 검증의 한계와 기존 지적 처리

- 고정 난수 0.99는 회전 횟수 계산의 상한이지만 **전체 애니메이션 시간의 최악 경로라는 증거는 아니다**. `frontend/src/App.vue:1427`에서 중간 문자도 동일 난수를 사용하여 같은 Z가 반복되고, `:1450`의 현재 문자와 같으면 즉시 완료하는 분기를 탄다. 이번에도 고정값은 일반 난수보다 빨랐다. 따라서 표의 `worst-*`는 기존 E2E 이름을 따른 파일명이며 실제 시간 최악이라는 판정이 아니다. 일반 난수 결과를 독립 근거로 함께 제공했다.
- 2800ms 안전 타이머는 실행 예약이다. 이벤트 루프 장기 지연·탭 백그라운드·저사양 실기기는 검증하지 않았으며, 소스만으로 모든 환경에서 정착≤2800ms가 절대 보장된다고 단정하지 않는다.
- r1 S1 저장 안내 외경30px 관찰은 PM이 수용한 상태로 보존한다. 이번에 28px로 바뀌었다거나 재시험으로 닫혔다고 주장하지 않는다. r2 재작업과 직접 관련 없는 스튜디오 전체 재검수는 수행하지 않았다.

## 확인한 개선·고정 체크리스트

- **주인공/행 구성**: A01 기본 코스와 A02 비엔나 1900이 두 시각표 행으로 구분된다. 상세는 제목·소개·미션 행 구조, 넓은 콘텐츠 카드 면 없음. 모바일은 순번·제목/시간·형식/상태가 행 안에서 줄바꿈한다. 12행을 가로 스크롤 없이 읽을 수 있다.
- **노선색/배지**: A 공통 배지·A01/A02 원형 정류장과 코딩/게임/시뮬 테두리 배지 유지. 입력과 실행 버튼에 조작 면을 사용한다.
- **영어 간판/카피**: 주요 UI는 한국어. ‘시뮬 · 택시 배차 엔진’ 및 결과의 재사용 설명은 구현 설명 비중이 크므로 향후 사용자에게 필요한 계산 한계/결과 범위 설명으로 다듬는 편이 낫다. 콘텐츠 파일의 원문은 변경하지 않았다. 별도 코스 HTML 목업 대신 PM의 `design/advisor-course-spec.md` §1과 `advisor-surfaces-spec.md`의 코스 책임을 기준으로 삼았다.
- **375/터치**: 375/390/1440 다크·라이트의 목록·기본/비엔나 상세·시뮬에서 가로 넘침 0. 비엔나 상세와 시뮬의 실제 이동/입력/버튼/summary는 40px 미만 없음. 게임/코딩 페이지 전체 접근성 통과로 확대하지 않는다.
- **라이트**: 라이트 설정에서 테마 전환 확인. 목록·상세·시뮬의 제목/행/형식 배지 구분을 캡처로 대조했다. 전 텍스트 대비비 전수 검사는 범위 밖이다.
- **스플래시 10초**: Advisor 직접 경로 검수이며 모선 스플래시는 변경/재검증하지 않았다.

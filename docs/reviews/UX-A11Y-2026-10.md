### 여행 도시 시트·정차역 편집 시트

Chromium 375/1440 보충 검수에서는 모바일 `노선도 펼치기`를 먼저 키보드로 활성화한 뒤 도시 링크에 도달했다. 최초 검사에서 접힌 지도 링크를 찾지 못한 것은 제품 결함이 아니며 보충 결과로 대체한다.

- 도시: `프라하 · DAY 1–2 정차역 상세` → Enter. dialog 이름 `프라하`, 내부 닫기·지도 링크 간 Tab 순환. Shift+Tab도 내부 유지, Escape 후 dialog0·원래 도시 링크로 복귀.
- 정차역: `11일차 인천` 선택 → `13:10 인천 도착` → Enter. 읽기 순서: 닫기 → 일차/시각 → 제목 → 먹은 것 textbox → 원화 금액 spinbutton → 메모 textbox → 더 적기 → 저장 전 status → 정차역 저장. Tab 순환 내부 유지, Escape 후 dialog0·원래 도착 버튼으로 복귀. 입력/저장/실데이터 업로드는 하지 않음.
- 근거: [followup.json](UX-A11Y-2026-10-assets/followup.json), [모바일 도시 시트](UX-A11Y-2026-10-assets/chromium-375-city-followup.png), [모바일 정차역 시트](UX-A11Y-2026-10-assets/chromium-375-stop-followup.png). WebKit followup의 미도달/remaining1은 위 환경 제약을 포함하므로 PASS/제품 결함 판정 근거에서 제외한다.

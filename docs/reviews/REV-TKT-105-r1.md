## [블로커] 표·사진의 편집 표면 — 본문 인라인이어야 한다
- 현재: 표는 다이얼로그('표 만들기/편집')에서 행·열을 조립해 삽입하고 본문에는 **참조 토큰**만 남는다. 사진은 data URL 문자열이 본문에 그대로 보인다 (UX-01). PO: "오른쪽에서 표를 직접 만들어서 넣는 건 아니지? 뭔가 이상한데".
- 기준(스펙 §6 개정판): 도구 메뉴 = 버튼 3개(사진·H1/H2/H3·표 삽입). '표 삽입' → **본문 커서 위치에 2×2 표가 실제로 보이고**, 편집은 그 표 위에서(hover 오른쪽 `+열`·아래 `+행`, 셀 `⋯` 삭제, Tab 이동). 사진도 본문에 **썸네일 블록**으로.
- 방향: 편집 표면을 **블록 시퀀스**로 — 텍스트 블록(기존 textarea 유지) · 표 블록(인라인 그리드 편집기) · 사진 블록(인라인 이미지). **`tables` 구조화 데이터·저장/복원/발행 렌더 로직은 그대로 두고 편집 표면만 옮긴다** — 참조 토큰은 블록 경계의 내부 표현으로만, 사용자에게 절대 노출 금지. 다이얼로그 조립 UI 제거.

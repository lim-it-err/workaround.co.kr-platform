[375 다크](UX-TKT-102-r13-assets/home-375-dark.png), [1440 다크](UX-TKT-102-r13-assets/home-1440-dark.png), [390 라이트](UX-TKT-102-r13-assets/home-390-light.png).

## 검증과 고정 체크리스트

- **빌드/실렌더**: Node 24.19.0, Vite 6.4.3, 격리 복사본 Pages-base build **57 modules** 성공. localhost:4193 Chromium에서 홈·스플래시 × 375/390/1440 × 다크/라이트 **12조합 overflow 0**. 57 modules에는 다른 FE의 작업 중 앱 변경도 포함되며 이를 수정하지 않았다.
- **주인공 1**: 홈=환승 홀에서 갈라지는 지도. 시작=브랜드/심볼/플랩. 지도 글자 가독성은 B1 잔존.
- **면/노선색**: 홈은 행·hairline·선·배지, 스플래시는 큰 외곽 면 없이 플랩 셀 유지. 통계 타일 증설 없음.
- **영어 간판/카피**: 지정 플랩 문구 유지. 보조 노선명은 S1. 실제 10초 자동 이동이 없는 HTML 목업이라는 기존 r9/r12 제약은 동일하다.
- **375/터치**: 넘침 0, 홈 링크 I1 미충족. 스플래시 링크 ≥44px.
- **배지/10초**: 노선 문자 배지·C 심볼 유지. 스플래시 변경은 `.ticker::before{display:none!important}` 한 줄뿐임을 전체 파일 비교로 확인했다. r12의 10초 실제 경과·3문구·3티커·reduced-motion 검증을 재사용하고, 이번에는 8.1초 정착 상태와 홈 이동을 확인했다. 변경 없는 엔진을 재검증 완료라고 중복 주장하지 않는다.
- **라이트**: 홈 라이트 실렌더 확인. 스플래시 고정 다크와 안내 대비 I3 확인.
- **탐색**: 현재 스플래시→홈 클릭, 홈 Tab→공개 아카이브→Enter 이동 확인. 홈 11개 href가 r12c와 동일해 기존 전수 클릭 증거를 재사용했다.
- **정적 경계**: 두 파일 snapshot/dist 일치, 근거 기록 시 원본과 SHA 일치. script·외부 의존 추가 없음. [재현 스크립트](UX-TKT-102-r13-assets/check.cjs).

PM은 B1/I1~I3의 수정·후속 배정과 S1을 판단하면 된다. Safari/WebKit·전체 스크린리더·실배포는 미검증이다. 이 보고서 작성 이후 다른 버전이 생기면 SHA를 대조해 변경분만 별도 검수한다.

## 목업 대조와 고정 체크리스트

- **주인공 1**: 허브는 최근 글 제목, 보관함은 제목/연도별 글 행, 상세는 본문. 최근 글의 실제 제목이 바뀌어도 위계는 유지된다. [허브 1440](UX-TKT-113-r1-assets/hub-1440-light.png), [보관함 1440](UX-TKT-113-r1-assets/archive-1440-dark.png), [상세 375](UX-TKT-113-r1-assets/post-375-dark.png).
- **면은 조작부만 / 노선색은 선·배지**: 콘텐츠 카드 그리드를 제거했고 좌측 3px B 노선선·행 구분선을 유지한다. 기존 공통 상단바/외곽 프레임은 이번 본문 전환 범위와 구분한다. 상세 외곽 배경은 transparent, 폭은 1440에서 720px.
- **영어 간판·분류**: 본문 UI 간판은 최근 글/글 보관함/연도 표기. 분류는 날짜 옆 한 개, 공개 목록은 published만 표시된다. 공개 제목·본문의 영문 콘텐츠를 UI 간판 위반으로 세지 않는다.
- **카피 정합**: 최근 글·새 글 쓰기·보관함·생각이 지나간 자리·← 보관함·이어서 쓰기 →를 목업과 대조했다. 가짜 목업 문장 대신 테스트용 글 데이터를 넣었고, 실제 사용자 저장소를 읽지 않았다. [기준 허브](UX-TKT-113-r1-assets/mockup-blog-hub-375.png), [기준 보관함](UX-TKT-113-r1-assets/mockup-blog-archive-1440.png), [기준 상세](UX-TKT-113-r1-assets/mockup-blog-post-1440.png). 상세 목업 원본의 max-width 680px보다 **티켓의 명시값 720px**을 적용한 것으로 확인했다.
- **375 넘침/터치**: 3화면 × 375/390/1440 × 다크/라이트 18조합에서 html/body/page-scroller/검수 본문의 가로 overflow 0. 보관함 행 높이 61px, 상세 하단 이동 40px, 허브 두 주요 버튼 53.81px. 최근 글 제목은 I1.
- **배지·10초**: B 원형 문자 배지 유지. 스플래시 10초는 이번 변경 범위 밖으로 재검증하지 않았다.
- **라이트**: 3폭 모두 실렌더, 본문 제목/내용은 읽을 수 있고 보조 글자 I2가 남는다. 공통 하단 노란 활성 글자의 기존 대비 문제는 UX-TKT-110-r1의 후속이며 이번 신규 건수에 중복 합산하지 않았다.

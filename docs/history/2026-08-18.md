## [codex-2] TKT-085 Pages+Tunnel 하이브리드 구현, 컨테이너 게이트 차단

- **무엇을**: D-011에 맞춰 Pages 빌드/Wrangler 배포 스크립트, `/api/*` Pages Function, `cloudflared` tunnel compose 프로필을 추가했다. 기존 Caddy는 `local`/`caddy` 레거시 프로필로 보존하고 네트워크 정책·PO 체크리스트를 갱신했다.
- **검증**: compose 3개 프로필 config, Vue production build, Pages Function 문법·고정 원점·503 격리, JDK 21 gateway package, secret 패턴, diff check 통과. JDK 테스트는 Mockito agent 제약 때문에 샌드박스 밖에서 재실행해 통과했다.
- **차단**: 샌드박스 밖에서도 Docker daemon socket 연결이 되지 않아 축소 완료 게이트인 gateway 기동과 cloudflared 컨테이너 실행을 수행하지 못했다. 티켓을 `blocked`로 전환했으며 Docker Desktop daemon 기동 후 두 게이트만 재실행하면 된다. Pages 실배포와 Tunnel 인증은 PO 계정 단계다.

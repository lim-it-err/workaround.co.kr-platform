# 2026-07-07

## 요약

`TKT-070` 으로 스플래시 플랩을 실제 split-flap 에 가깝게 정상화했다. 이제 셀마다 현재 글자와 다음 글자의 반쪽 판이 분리되어, 하단 판이 먼저 접히고 상단 판이 이어 올라오는 물리감이 보인다.

## 수행 내역

1. `frontend/src/App.vue` 에 셀별 플랩 상태(`currentCharacter`, `topStatic`, `bottomStatic`, `topFlip`, `bottomFlip`)와 중간 문자 시퀀스 엔진을 추가했다.
2. 레퍼런스 mockup 의 리듬을 따라 행/열 시차, 문자판 분기, 3~9회 중간 플립, 마지막 장 반동 정착을 실제 스플래시 보드에 이식했다.
3. `frontend/src/styles.css` 의 플랩 반쪽 판 배경, z-index, 애니메이션 타이밍을 조정해 단순 글자 회전이 아니라 반쪽 패널이 실제로 접혀 넘어가도록 정리했다.
4. `prefers-reduced-motion` 에서는 결과만 표시하고, `다시 재생` 버튼과 자동 전환 동선은 유지했다.
5. 검증: `tools/run-frontend-build.ps1` 통과, `tools/run-gateway-tests.ps1` 통과, `tools/check-docs-encoding.ps1` 통과.

## 메모

- 남은 조정 포인트는 취향 영역이다. 필요하면 후속에서 마지막 반동 각도와 전체 전개 시간을 소폭 다듬으면 된다.

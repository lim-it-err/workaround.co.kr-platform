# 취향 노선 (Taste Line) 정의

## 목적

10개의 간단한 A/B 선택으로 지금의 취향을 읽어, 어울리는 **와인 한 병과 커피 한 잔**을 추천한다. 계정도 로그인도 없이 즉시.

지하철 콘셉트: `Line P / Palate`, 승강장 이름 "테이스팅 바". 환승 홀 노선도(C 방식)의 한 지선으로 붙는다.

## 2^10 문제와 해법 (핵심 설계)

10개 A/B 를 조합으로 풀면 `2^10 = 1024` 가지를 미리 만들어야 해서 폭발한다. 대신 **규칙 기반 스코어링**으로 조합을 만들지 않는다.

- 10개 질문 각각이 몇 개의 **취향 축**에 점수를 더한다.
- 답변을 합산하면 사용자의 **취향 벡터**가 나온다.
- 와인 24종·커피 24종에 같은 축의 프로파일 값을 미리 매겨 둔다.
- 사용자 벡터와 각 후보의 거리(가중 유클리드)를 재서 **가장 가까운 와인 1종 + 커피 1종**을 추천한다.

이러면 미리 만들 데이터는 조합 1024가 아니라 **질문 10 + 와인 24 + 커피 24 = 58개 항목**뿐이다. 런타임 토큰 0, 즉시 계산.

## 취향 축 (예시 6~7축)

- `sweetness` 단맛 ↔ 드라이
- `body` 가벼움 ↔ 묵직함
- `acidity` 산미 낮음 ↔ 높음
- `fruitiness` 흙/견과 ↔ 과일/꽃
- `roast` (커피) 라이트 ↔ 다크 / (와인) 영 ↔ 오크
- `bitterness` 부드러움 ↔ 쌉쌀함
- `adventurous` 익숙함 ↔ 새로움

각 질문은 1~2개 축에 +/- 가중치를 준다. 예: "아침을 깨우는 진한 맛 vs 은은하게 퍼지는 맛" → `roast +2, body +1`.

## 매칭 알고리즘

1. 답변 10개를 축별 점수로 합산 → 사용자 벡터 `u`.
2. 각 후보 `c` 의 프로파일 벡터와 가중 거리 `dist = sqrt(Σ w_k (u_k - c_k)^2)`.
3. 와인 목록에서 최소 거리 1종, 커피 목록에서 최소 거리 1종 추천.
4. 동점이면 `adventurous` 축이 가까운 쪽 우선(취향 결의 일관성).

## 데이터 스키마

```json
// questions.json (10개)
{ "id": "q1", "a": "아침을 깨우는 진한 맛", "b": "은은하게 퍼지는 맛",
  "axesA": { "roast": 2, "body": 1 }, "axesB": { "roast": -2, "body": -1 } }

// wines.json / coffees.json (각 24종)
{ "id": "w07", "name": "...", "region": "...", "note": "...",
  "profile": { "sweetness": -1, "body": 2, "acidity": 1, "fruitiness": 0, "roast": 1, "bitterness": 1 },
  "why": "묵직한 바디를 고른 당신에게, 오크 숙성의 무게감이 어울립니다." }
```

- `why` 는 추천 이유 한 줄. 기본은 정적 템플릿(축 기반 문구). 토큰 0.

## API 콜 옵션 (선택)

- 기본 추천/이유는 전부 정적이라 토큰 0.
- "왜 이 조합인지 더 풀어서" 버튼을 누르면 그때만 Claude API 로 개인화 설명을 생성하는 **옵션**을 둘 수 있다(발견 노선의 depth 2~3와 같은 gateway 프록시 재사용). 기본 흐름은 정적, API 는 부가.

## 범위

- 포함: 10 A/B 질문, 취향 축 스코어링, 와인 24·커피 24 프로파일 DB, 매칭 알고리즘, 테이스팅 바 UI, 결과 카드(와인+커피+이유), 다시 하기.
- 제외: 실제 구매 링크/재고 연동, 사용자 취향 이력 저장(첫 버전은 세션 1회), 음식 페어링 확장(후속).

## 열린 질문

- 축 개수: 6축(간결) vs 7~8축(정밀)? 기본안: 6~7축.
- 결과 다양성: 상위 1종만 vs 상위 2~3종 중 선택? 기본안: 각 1종 + "다른 후보 보기".
- API 설명 옵션을 첫 버전에 넣을지: 기본안은 제외(정적만), 후속에서 발견 노선 프록시 재사용.
- 대상 버전: 기본안 `v0.9.0`.

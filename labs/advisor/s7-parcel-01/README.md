# 베개가 책보다 비싼 이유 — 택배 운임 계산기

## 요구사항

1. 부피중량(g) = 가로 × 세로 × 높이(cm³) × 1000 ÷ 6000. 청구중량 = max(실중량, 부피중량)을 0.5kg(500g) 단위로 올림합니다. 검증: 소포 1 은 24,000cm³ → 4,000g → 청구 4.0kg, 소포 2 는 80,000cm³ → 13,333.3g → 청구 13.5kg.
2. 기본 운임은 RateTable.baseFee(청구중량의 0.5kg 단위 개수)로 구합니다. 2.0kg 이하 4,000원, 5.0kg 이하 5,000원, 10.0kg 이하 6,500원, 20.0kg 이하 8,000원, 30.0kg 이하 10,000원.
3. 총운임 = 기본 운임 + 권역 할증(SAME 0원, OTHER 1,000원, JEJU 3,000원) + 도서산간이면 5,000원 + 착불이면 500원. 할증이 0원인 항목은 출력에서 빼고, 있는 항목만 「 + 」로 잇습니다(App.java 기대 출력 그대로).
4. 접수 불가 조건: 세 변의 합이 160cm 초과, 가장 긴 변이 100cm 초과, 실중량이 30kg(30,000g) 초과. 하나라도 걸리면 운임 대신 「[이름] 접수 불가: 이유」 한 줄을 돌려줍니다(여러 개면 위 순서의 첫 번째, 이유에는 넘은 기준값 160cm·100cm·30kg 을 넣습니다). 소포 4 는 「접수 불가: 세 변의 합 170cm 가 160cm 를 넘습니다」.
5. 출력의 부피중량과 실중량은 kg 소수 첫째 자리까지, 둘째 자리에서 올림해 표시합니다(13,333.3g → 13.4kg). 계산에는 표시값이 아니라 g 정수와 0.5kg 단위 개수를 씁니다.
6. 다음 달에 착불 수수료가 조정될 예정이고, 사장님은 "부피 기준이 6,000 에서 5,000 으로 바뀔 수도 있다"는 공지를 받았습니다. 아직 확정된 숫자는 없습니다.

# dev-022 — 신규 미니게임 3종·24판

## 목표

최소 재현, 둘이 동시에, 격벽 두 장을 각각 8판으로 구현하고 전체 연습 카탈로그에 연결한다.

## 플레이 계약

- 최소 재현: 조건을 제거해도 버그가 남는지 선택하고 최소 조건·후일 비용·해설을 공개.
- 둘이 동시에: A/B 단계의 실행 순서를 고르고 깨진 불변식·복구·해설을 공개.
- 격벽 두 장: 전파 그래프의 연결 둘을 차단하고 생존/포기 기능·권장을 비교.
- practice 결과만 저장하며 daily 보상에는 영향 없음.

## 검증 게이트

- 각 8판, ID 고유, 필수 결과/후일담/해설 존재.
- 엔진 단위 테스트 3종 + 대표 E2E 3종.
- `npm run test:unit`, `npm run test:e2e`, `npm run build`, 375px 오버플로 0.

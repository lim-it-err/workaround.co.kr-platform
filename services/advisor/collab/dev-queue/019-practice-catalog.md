# dev-019 — 전체 게임 카탈로그·daily/practice 분리

## 목표

`/games`의 날짜 기반 오늘 모드를 유지하면서 모든 정적 판을 무제한 연습한다.

## 범위

- 게임별 전체/완료/미완료/예상 시간 카탈로그.
- `처음부터`, `다음 판`, `랜덤`, `아직 안 본 판`, 개별 연습 기록 삭제.
- 연습 상태·필터·마지막 판은 로컬 저장하되 daily 세션·스트릭·시즌 스탯과 분리.
- 사건 파일은 practice에서 1~5화 자유 열람하고 다음 화 제목·정답은 접는다.

## 검증 게이트

- practice 실행이 daily 세션·시즌 획득 이력을 변경하지 않는 단위 테스트.
- 카탈로그 선택·재도전·새로고침 복원 E2E.
- `npm run test:unit`, `npm run build`, 375px 오버플로 0.

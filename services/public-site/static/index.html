workaround.co.kr

작은 서비스와 시뮬레이터를 천천히, 그러나 실제로 운영합니다.

이 페이지는 공개 진입점입니다. 내부 통합 프리뷰는 별도로 유지하고, 공개 웹사이트는 플랫폼 소개와 운영 원칙을 명확하게 전달하는 데 집중합니다.

대표 도메인 보기 보조 도메인 정책

현재 방향

공개 사이트는 `workaround.co.kr` 를 대표 도메인으로 사용하고, `workaround.kr` 은 이 주소로 리다이렉트합니다.

배포 원칙

첫 공개 배포는 사용자가 가진 서버 위 Docker 기반으로 운영하고, TLS 와 도메인 정책은 reverse proxy 계층에서 관리합니다.

플랫폼 성격

내부에서는 gateway, worker, 시뮬레이터, 외부 Ollama 런타임이 느슨하게 연결되고, 공개 페이지는 이 구조를 한 문장으로 소개하는 역할에 머뭅니다.

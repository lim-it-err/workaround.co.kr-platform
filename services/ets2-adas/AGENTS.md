# `services/ets2-adas/` 폴더 규칙 (이 폴더를 만지는 모든 Codex)

> 상위 규칙: 저장소 루트 `CLAUDE.md`·`docs/`. 개발·커밋은 **맥의 단일 워킹트리**에서만(D-028 개정). `.100` Windows 는 배포 대상이며 SSH(윈도우 호스트 OpenSSH `Host ets2-100`, 기존 6445 컨테이너 채널 아님)로만 운용한다.

- **비밀값**: R2 키·토큰·프로필 경로·Steam ID 는 `.100` 의 `.env`·로컬 설정에만. 커밋·로그·티켓에 붙이지 않는다(`IMPORT-NOTE.md` 치환 규칙 유지).
- **안전**: 게임 제어 경로(arm 토큰·300ms 만료·F8·브레이크 중단)는 완화하지 않는다. 자동 복구(견인·수리)는 PO 가 명시 승인한 범위만. 페이지가 호출할 수 있는 것은 PoC API 뿐(D-025 PO 답).
- **PoC 제어 로직·네이티브 ABI** 는 티켓이 요구할 때만 바꾼다. 바꾸면 `tests/native-smoke.cpp`·`tests/*.cjs` 먼저.
- **원격 실행 원칙**: 창 캡처·게임 입력이 필요한 프로세스는 SSH 세션에서 직접 띄우지 않는다 — 대화형 세션의 작업 스케줄러 태스크를 `schtasks /Run` 으로 호출(`deploy/`). 검증은 실게임에서 돌린 것만 "확인", 그 외는 "하네스/모사" 로 구분. 로그·결과는 `docs/qa/env100/` 에 재연 가능하게.
- 모호하면 구현으로 우회하지 않는다 — 티켓 `## 질문/에스컬레이션` 에 `[구체화 질문]`/`[반박]`.

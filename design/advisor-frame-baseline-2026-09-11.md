## 1단계 구현 기준

- PM 2026-09-10 지시에 따라 별도 정적 빌드(티켓 2안)를 유지한다. TKT-103이 빌드 병합·SPA 복구를 소유한다.
- A의 경로는 `/advisor/`, 렌더 방식은 `static`으로 노선 단일 소스에 둔다. project base를 합성해 실제 앵커로 이동하며 새 탭·키보드 접근을 보존한다. SVG는 같은 목적지로 이동하는 시각 요약이다.
- Advisor 모듈 내부는 건드리지 않고 앱 셸 메뉴에 `← 환승 홀` 링크를 추가한다. 복귀 목적지는 빌드 base의 마지막 `advisor/`만 제거해 구한다. 외부 referrer나 사용자 URL을 신뢰하지 않는다.
- 기본 base `/`로 단독 실행한 Advisor에서는 잘못된 자기 자신 복귀 링크를 표시하지 않는다.
- 원래 콘텐츠·닉네임·미션 메뉴·저장 키·다크 스타일은 보존한다. 전체 테마·역명판을 섞어 부분 라이트 화면을 만들지 않는다.

## 검증·완료 경계

- Pages 병합 산출물에서 A 목록/SVG 진입, Advisor 내부 이동·깊은 경로 새로고침·복귀를 확인한다. 모선은 다크/라이트 각각 375px, Advisor는 기존 고정 다크를 두 OS 선호에서 확인한다.
- 단독 Advisor 기본 base의 내부 라우팅을 유지한다. 새 외부 폰트·이미지·의존성·배포 설정은 추가하지 않는다.
- 1단계 완료는 전체 TKT-079 완료가 아니다. 전체 색·타이포·간격·역명판 통합은 원래 완료 기준으로 남으며, 티켓은 started를 유지한다.

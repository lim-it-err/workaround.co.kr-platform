# 노선 teardown — 실험선 분리와 노선 재편 제안 (v0.9)

- 작성: PM(Claude Opus 5.5), 2026-10-25 · 대상 v0.9.0(블랙 디자인과 함께 IA 개편) · 결정 대기: ASK Q-025
- 요청: PO 「실험선도 두개로 구분하자. 발견 메뉴는 뭐지? 그리고 저런것도 하고싶은데 약간 하루에 새로운 지식 5개씩. 일일5지? 뭐 이런거 이걸 해서 너가 한번 teardown 해서 노선을 여러개로 분리해봐」

## 1. 지금 노선 (v0.8.1 기준)

| 노선 | 큰 역 | 작은 역 | 성격 |
|---|---|---|---|
| 기록선 | 여행(V) · ~~블로그(B, 운행 중단)~~ | 노선도 | 내 기록 |
| 실험선 | Advisor(A) · 미스터리 트레인(S) · 발견(D, 미개통) · 자취 밥상(P) | 코스·미션 / 격납고·유로트럭·유로트럭 개발자·엘리베이터·택시·화이트채플 | **배움 + 놀이 + 생활 + 실시간 관제가 한 줄에 섞임** |
| 기지선 | Work(W, 운영 노트) · Runtime(R) | 작업 흐름 · 실행 상태 | 운영 |

### 문제
1. **실험선이 과적재**: 큰 역 4 + 작은 역 7. 성격이 다른 네 가지(배움·놀이·생활·관제)가 한 노선이라 "이 노선은 무엇인가"에 답이 없다.
2. **미스터리 트레인이 창고가 됨**: 시뮬 2개·아케이드·유로트럭 2면이 모두 그 아래 작은 역. 유로트럭은 시뮬이 아니라 실제 게임 관제라 성격이 다르다.
3. **발견(D)은 이름만 있고 비어 있다**: 2026-08 설계(`docs/discovery-line-definition.md`)는 "하루 주제 하나를 세 갈래로 파고들기". 구현 티켓 065·066 은 미착수.
4. **노선마다 큰 역 수가 들쭉날쭉**(기록 1·실험 4·기지 2)이라 노선도 균형이 깨진다.

## 2. "발견" 은 무엇이었나 → "일일 5지" 로 다시 정의

- 원래 설계: 날짜 시드로 하루 주제 1개, 간단 설명 → `더 깊이 / 더 넓게 / 뜻밖의 각도` 3갈래로 depth 3 까지. depth 0~1 은 정적, 2~3 은 로컬 LLM.
- PO 의 "하루에 새로운 지식 5개" 가 이 자리에 가장 잘 맞는다. 제안: **발견 역을 "일일 5지"로 개통.**
  - 하루 5개 지식 카드(각 2~3문장 + 출처 링크 1). 같은 날은 누구에게나 같은 5개(날짜 시드).
  - 카드마다 `더 알아보기` 한 단계(정적). 원래의 3갈래·depth 3 은 로컬 LLM 이 붙는 v1.1 에서.
  - 콘텐츠: 처음엔 30일치(150장) 정적, 공식·신뢰 출처 필수(U-37 콘텐츠 규칙). v1.0 이후 일일 배치(로컬 LLM + 출처 검증)로 자동화 — 실시간 호출 0 원칙과 맞다(D-032).
  - 위험: **지식 카드의 사실 오류**가 가장 큰 위험이다. 출처 없는 카드는 싣지 않고, codex-9 가 표본 검수.

## 3. 제안 — 노선 5개, 노선마다 큰 역 2개(환승 홀 양쪽)

지금 노선도 원칙(r16: 노선이 환승 홀을 직선으로 통과)을 그대로 쓰면, **노선 하나 = 환승 홀 양쪽에 큰 역 하나씩**이 가장 깔끔하다. 노선 5개면 큰 역 10자리.

| 노선 | 한쪽 | 반대쪽 | 작은 역 |
|---|---|---|---|
| **기록선** | 여행 | 블로그(운행 중단 표시, 흐림) | 노선도 |
| **배움선**(실험선 분리 ①) | Developer Advisor | 일일 5지(구 발견) | 코스·미션 / 지난 발견 |
| **놀이선**(실험선 분리 ②) | 격납고(구 미스터리 트레인) | 유로트럭 | 엘리베이터·택시·화이트채플 / 뷰어·개발자 |
| **생활선** | 자취 밥상 | 취향(와인·커피, 예정 — 구 067 자리) | 장보기 목록(예정) |
| **기지선** | 운영 노트 | Runtime | 작업 흐름 / 실행 상태 |

- PO 가 말한 "실험선 두 개"는 **배움선 + 놀이선**이다. 자취 밥상은 배움도 놀이도 아니라 생활선으로 따로 뺐다 — 이걸 실험선에 남기면 2개로는 다시 섞인다.
- 유로트럭은 미스터리 트레인 밑 작은 역에서 **큰 역으로 승격**(실제 게임 관제·실시간 화면이라는 독자 성격).
- 5노선 × 직선 통과면 지도에 팔이 10개다. 블랙 디자인(A 터미널)에서는 원형 노선도 대신 **노선별 가로 줄**(목업 A 의 `● 역 ──── ● 역`)로 그리는 게 더 단순하다 — v0.9 디자인과 같이 가는 이유.

### 대안
- **B안(최소 변경)**: 실험선만 배움선(Advisor·발견)과 놀이선(미스터리 트레인·자취 밥상)으로 쪼갠다. 노선 4개. 변경은 작지만 밥상이 놀이선에 어색하게 남는다.
- **C안(최대)**: 위 5노선 + 유로트럭을 "관제선" 으로 독립(6노선). 지금 콘텐츠 양에 비해 과하다.

PM 권고: **5노선 안(A)**.

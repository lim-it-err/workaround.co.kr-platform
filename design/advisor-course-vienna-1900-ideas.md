# Advisor 코스 아이디어 — "비엔나 1900" (역사·미술 도메인)

> 발단: PO 2026-09-14 벨베데레(클림트 〈키스〉) 관람 — "역사와 예술 관련 미션을 만들 만한 게 없을까?"
> 원칙: 도메인은 미술·역사, 문제는 기술(데이터·알고리즘·모델링). 기존 4형식(사건 파일 / boundary / probe / 스와이프) + 시뮬 재사용. 코스 = D-013 정류장.

| 1 | 〈키스〉의 출처를 증명하라 | 사건 파일 | 소유 이력 이벤트 소싱, 문서 간 모순(날짜 역전·이중 매각) 탐지 | 블로흐-바우어 반환 소송(2006) |

## 구조 제안 — 노선 환승
- 여정 노선도(V) 정차역(벨베데레·쇤부른·할슈타트)에 **"이걸로 미션 만들기 →"** 링크 → Advisor(A) 코스 정류장 "비엔나 1900". 경험→배움 환승 = 순환선 컨셉의 실사용 예.
- Advisor 재편(감사 AS-R###-advisor-rethink) "미션·사건 파일" 표면의 첫 코스 후보.

## 코스 등뼈 — "그림은 왜 바뀌었나" (PO 2026-09-14 "역사별로 그림이 어떻게 변했는지")

원인(기술·사회·사상) → 결과(양식) 구조. 기술·계보·분류·공간 4축.

| # | 미션 | 형식 | 기술 문제 | 배우는 것 |
|---|---|---|---|---|
| A | 양식 연대 추정기 | 스와이프 → 규칙 트리 | 특징(원근법·금박·붓터치·주제·채도)로 시대 분류, 답으로 결정 트리 구성 | 클림트 금박이 '고딕'으로 오분류되는 함정(비잔틴 회귀) |
| B | 안료 연표가 양식을 바꿨다 | 시계열 상관 | 프러시안 블루 1706 → 코발트 1802 → 합성 울트라마린 1826 → 튜브 물감 1841 → 인상주의; 팔레트 추출·지연 상관 | 기술→예술 인과 |
| C | 영향 그래프 | DAG·위상 정렬 | 사조·화가 영향 관계 모델링, 사이클 감지, 연대표 자동 생성 | 쌍방 영향 입력 오류 |
| D | 원근법의 발명 | 연습 게임(투영) | 평면(고딕)→소실점(브루넬레스키)→투영 행렬 렌더 | 공간 표현의 수학 |
| E | 한 화가의 변화 — 클림트 | 변곡점 탐지 | 작품 피처 시계열(천장화→황금기→후기 색채)에서 변화점 | 시계열 분석 |
| F | 벨베데레를 연대순으로 걷기 | 정렬·경로 | 소장품 메타(연도·사조·전시실) 위상 정렬 + 전시실 최단 경로 | 그래프·경로 |

응용편 = 위 표 1~6(출처 증명·금박 손상·큐레이션·계승 규칙·입장 큐·소금광산). 총 12 미션 = 코스 1개 분량.

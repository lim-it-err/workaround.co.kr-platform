# UX 전면 재작업 시안 (2026-07-05)

서울 지하철 콘셉트를 유지한 채 전면 재작업한 3개 시안입니다.
각 HTML 은 외부 리소스 없이 완전히 자체 완결이므로, 파일을 브라우저로 바로 열면 됩니다.

## 검토 방법

1. 원하는 시안 HTML 파일을 브라우저로 연다 (더블클릭).
2. 페이지를 열면 스플래시의 스플릿 플랩이 자동 재생된다. `다시 재생` 버튼으로 반복 확인.
3. 상단 고정 헤더의 토글 버튼으로 라이트/다크를 반드시 둘 다 확인.
4. 스크롤로 5개 구간을 순서대로 본다: 스플래시 → 환승 홀 → 블로그(목록+상세) → 엘리베이터 승강장 → 모바일 미리보기.
5. 창 폭을 좁혀 반응형 재배치도 확인 (모바일 미리보기 구간은 390px 프레임으로 고정 제공).

## 시안 구성

### 시안 A — `variant-a-seoul-signage.html` 「서울 사인 정제」

- 현행 시스템의 정제판. Base Metal/Panel Surface 다크 톤 + Safety Yellow/Exit Green 액센트를 유지하되, 장식을 걷어내고 정보 위계를 강화.
- 볼 것: 역명판형 승강장 헤더(인접역 표기), 안전선 노랑의 절제된 사용(현재 위치·포커스·섹션 레일), Exit Green 진입 CTA, tabular figures 숫자 정렬.
- 기본 다크. 라이트는 "주간 역사" 톤.

### 시안 B — `variant-b-paper-archive.html` 「종이 아카이브」

- 블로그 우선. 기록 보관함/잡지 무드에 지하철 사인 액센트를 융합. 명조 표제, 점선 리더 목차, 도서 스탬프형 노선 칩.
- 볼 것: 환승 홀의 표지+목차 구성, 서지 목록형 아카이브(카드 상자 없음), 레터프레스 질감의 플랩 보드(라이트=크림 판, 다크=호두나무 판).
- 기본 라이트. 다크는 "야간 서고" 톤.

### 시안 C — `variant-c-night-line.html` 「야간 노선도」

- 노선도 다이어그램이 레이아웃 그 자체. 환승 홀이 문자 그대로의 SVG 노선도(블로그 굵은 본선 + 실험 지선 4개)로 그려짐.
- 볼 것: 노선도와 행 목록의 이중 표현, 순흑 최소형 플랩 보드, 노랑을 현재 위치 마커에만 쓰는 절제, 모바일의 세로 노선띠 재배치.
- 기본 다크(야간). 라이트는 "주간 노선도"(흰 종이 위 노선도).

## 공통 사항

- 플랩 연출은 세 시안 모두 동일한 기계 구조(반쪽 플랩 rotateX + 중간 글자 넘김 + 열 단위 시차 + 착지 반동)이며, 재질과 속도만 시안별로 다릅니다. 구현 레퍼런스로 사용 가능합니다.
- 모든 UI 카피는 한국어, 폰트는 시스템 스택(Pretendard 설치 시 우선 적용)입니다.
- `prefers-reduced-motion` 설정 시 플랩은 결과만 표시합니다.
- 블로그 글 5편, 상태 배지(공개/초안/보관), 글 상세 typography(제목/헤딩/본문/코드/인용)는 세 시안 공통 콘텐츠로 비교하기 쉽게 맞췄습니다.

## 피드백으로 확인하고 싶은 것

1. 세 시안 중 기본 방향 (또는 조합: 예 — 전체 골격 A + 블로그 구간 B).
2. 플랩 연출의 속도/반동감이 의도한 "매끄러움"에 맞는지.
3. 기본 테마(다크 우선 vs 라이트 우선).
4. 모바일 재배치 방식 중 선호 (A/B: 목록 접기, C: 세로 노선띠).

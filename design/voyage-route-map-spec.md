# 여정 노선도 스펙 — "지리 충실형 순환선" (2026-09-14)

> 발주: PO "그날 움직인 경로를 간소화된 깔끔한 노선도 형태로, 지하철 컨셉으로. 실질적인 거리와 방향은 유지. 노선 위에 커서를 올리고 클릭하면 그 날이 나오는 컨셉. 식당·먹은 것·금액, 사진·구글 지도 첨부." 구체화·확장은 PM.
> 목업: TKT-102 r7 `voyage-route.html` / 구현: TKT-109 `[FE]` (목업 승인 후 ready) / 데이터: 컬렉션 스펙 §1 에 필드 추가.

## 1. 핵심 은유

**여행 하나 = 순환선 하나.** 이번 여행의 이름이 이미 "중부유럽 순환선"이다 — 그대로 노선도가 된다.
- **역 = 도시** (프라하 · 체스키크룸로프 · 할슈타트 · 잘츠부르크 · 멜크 · 비엔나 · 부다페스트 · 브르노 · 프라하).
- **구간(역 사이 선분) = 일차.** 이동이 없는 날(비엔나 2일차, 부다페스트 2일차)은 역에 "정차" 표시(원 두 겹).
- **지리 충실**: 위경도를 등장방형 투영으로 그대로 SVG 좌표에 놓는다 — 실거리·방향 유지. 직선 연결이되 곡률 0(지하철 약도처럼 45° 스냅은 **하지 않는다** — PO 조건). 실제로 이 9개 도시는 지도 위에서 자연스러운 고리를 이룬다.
- 지나온 구간 실선(노선색), 남은 구간 점선, **현재 위치 pulse**(여행 중).

## 2. 상호작용 (목업은 CSS :hover/:target, 구현은 Vue)

- **구간 hover** → 툴팁 한 줄: `DAY 4 · 할슈타트 → 잘츠부르크 · 운전 3h30 · 지출 xx만원`.
- **구간 click** → 그날 카드가 지도 아래(모바일)/오른쪽(데스크톱)에 열린다: 경과 불릿 · 식당 기록 · 지출 한 줄 · 사진 · 한 줄 감상.
- **역 click** → 그 도시의 전부: 숙소 · 그 도시에서 먹은 것 · 사진.
- **양방향 연동**: 카드를 스와이프/스크롤하면 지도의 해당 구간이 하이라이트, 지도를 누르면 카드가 그 날로.
- 키보드: 구간은 `<a href="#day-n">` — Tab 이동·Enter 로 동일 동작 (접근성 겸 목업 무스크립트 구현 수단).

## 2-1. 일차 카드 = 세로 시간표 (PO 2026-09-14 추가 — 지하철·기차 앱 오마주)

구간을 누르면 열리는 "그날"은 글 카드가 아니라 **세로 정차역 시간표**다:

```
○ 08:00  숙소 체크아웃            ← 정차역 = 사건(시간 + 한 줄)
│
│  운전 2h30                       ← 구간 = 이동(모드·소요시간, 운전은 굵게)
│
○ 10:45  구시가 외곽 주차장
│
◐ 12:00  점심 · 식당명 · 280Kč     ← 접시 반원 = 식사 정차역 (탭하면 메뉴·금액·사진·지도)
├─ 비 오면 → 성 내부 투어로        ← 지선 = 상황 분기 (daySessions.branches)
│
○ 13:00  성 · 망토 다리 전망
│
◎ 18:00  저녁 · 구시가 골목        ← 이중 원 = 그날의 주인공 1
```

- **데이터 매핑**: 기존 `daySessions[].timeline[{time,title,detail}]` 이 그대로 정차역, `branches[]` 가 지선, `meals[]` 는 접시 정차역으로 끼워 넣는다. 새 스키마 발명 없음.
- **정차역 탭 → 상세**: 지하철 앱의 "역 정보"처럼 — **데스크톱: 오른쪽에서 슬라이드 인 되는 패널**(시간표는 그대로, 패널이 옆에 붙음), **모바일: 바텀 시트**(시간표 위로 반쯤 올라옴, 위로 끌면 전체). 상세 내용: 사건 설명 · 식당이면 메뉴·금액·구글 지도 링크·사진 · 그 정차역의 지출.
- 목업(r7)은 무스크립트라 `:target` 으로 패널/시트를 연다 — 정차역은 `<a href="#stop-3-2">`.
- 선의 색·굵기: 운전 구간은 노선색 굵게 + 소요시간 표기, 도보/시내는 가늘게, 휴식(카페 60~90분)은 점선 — 하루의 리듬이 선의 질감으로 보인다.
- 현재 시각 표시(여행 중, 오늘 카드만): 시간표 위에 얇은 "지금" 가로선 — 기차 앱의 현재 위치 마커 오마주.

## 3. 데이터 (컬렉션 스펙 §1 확장)

- 여행: `cities[{id, name, lat, lon}]`, `legs[{dayIndex, from, to, driveMin, km}]` (km 은 좌표에서 계산 가능).
- 일차 추가 필드: `meals[{slot:'아침|점심|카페|저녁', place, dish, amount, currency, mapUrl, photo}]`, `spend{items, total}`, `photos[{src, caption, mapUrl}]`.
- 첨부: 정적 사이트 → 사진은 `frontend/public/voyage/<trip>/…`(PM 등록), 정적 모드 임시 첨부는 localStorage(TKT-097 패턴), 서버 업로드는 TKT-053 뒤. **구글 지도는 URL 링크만**(임베드 금지 — D-009·D-014 외부 URL 허용 목록에 `maps.google.com`/`goo.gl/maps` 추가).

## 4. 재미 요소 (PM 제안 — 목업에서 가벼운 것부터)

1. **구간 굵기 = 운전 시간.** 3시간 구간은 굵고, 1시간 구간은 가늘게 — 거리(길이)와 시간(굵기)을 한 눈에.
2. **역 옆 접시 아이콘 = 그날의 한 접시.** 식당 기록 중 하나를 대표로 노선도에 올린다 ("체스키크룸로프 · 송어구이"). 클릭하면 식당 카드.
3. **구간 위 작은 표지판 = 지출 종류.** 주유·비네트·톨은 구간에, 숙소는 역에, 식비는 접시에 — 지출이 지도 위에 흩어져 보인다.
4. **계기판 헤더**: 누적 km(좌표 계산) · 누적 지출 / 계획 — 두 진행선.
5. **역 도장**: 도착한 역에 스탬프(TKT-090 스탬프 재사용) — 도장 찍힌 역이 늘어나는 게 진행 표시.
6. **회고 모드(종착 후)**: ▶ 누르면 열차 점이 노선을 일차 순서로 달리며 카드가 자동으로 넘어간다 — 여행 끝나고 다시 보는 용도. (구현 티켓, 목업은 정적 힌트만)
7-1. **환승 (PO 2026-09-14 채택)**: 정차역에 `이걸로 미션 만들기 →` — 경험(V)→배움(A) 환승, `design/advisor-course-spec.md` §3, TKT-125.
7. **노선망**: 컬렉션 화면에서 지난 여행(스페인·아이슬란드)의 순환선을 같은 축척의 유럽 지도에 나란히 — 여행이 쌓일수록 노선망이 된다.

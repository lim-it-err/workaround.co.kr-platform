# Advisor 디자인 통합 2단계 — TKT-079

## 방향과 경계

- 기존 미션 작업면 위에 모선의 A 노선 역명판을 연결한다. 별도 정적 빌드·내부 라우팅·콘텐츠·저장 흐름은 그대로 유지한다.
- 모선 `StationHeader.vue`를 Advisor 앱 셸에서 직접 재사용한다. 모듈 내부에서 외부 파일을 참조하지 않으며, 모선 앱이나 gateway를 실행하지 않아도 Advisor는 빌드·실행된다. 빌드는 모노레포 체크아웃을 기준으로 한다.
- 모선 전역 CSS 전체를 끌어오지 않는다. Advisor 앱의 토큰 어댑터에 TKT-071의 색·폰트·간격 및 A 코어/텍스트 짝을 맞추고, 토큰 일치 검증으로 드리프트를 감지한다. 모선 소스·배포 파일은 이번 단계에서 수정하지 않는다.
- 같은 오리진의 `workaround-theme` 설정을 공유한다. 기본 다크, 라이트 토글·새로고침 복원, 저장 차단 시 메모리 내 동작을 유지한다.
- 콘텐츠 파일·문구·보상/저장 로직은 불가침. 페이지별 고정 색상만 테마 토큰으로 바꾸며 코드 블록은 라이트에서도 어두운 판과 밝은 글자를 유지한다. 일반 입력 표면은 테마를 따른다.

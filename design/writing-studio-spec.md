# Writing Studio 전면 재설계 스펙 (2026-09-09)

> 발주: PO 2026-09-09 — "writing studio 디자인이 너무 조잡하고 어떤 기능이 있는지도 모르겠어. ux, ui 전부 전면 재검토해줘."
> 구현 티켓: TKT-100 `[FE]`. 카피 기준: `design/ux-copy-audit-2026-08-16.md` 원칙 6.

## 1. 실화면 감사 — 무엇이 조잡한가 (localhost:7010, 2026-09-09 PM 직접 확인)

1. **크롬 4겹**: station-topbar → 스튜디오 역명판 헤더 → draft/preview/publish 스테퍼 → 통계 타일. 에디터가 첫 화면에 안 보인다.
2. **상태 3중복**: 상태 chip + 스테퍼 + STATUS 타일이 같은 정보를 세 번 말한다.
3. **버튼 7개 혼재** (저장·미리보기·발행·보관·새 초안·서랍·뒤로) — primary 가 없다. "다음에 뭘 눌러야 하나"를 화면이 답하지 못한다.
4. **DRAFT SHELF / ARCHIVE SHELF 상시 노출** — 쓰기 영역이 화면의 절반 이하.
5. **영어 라벨**(SLUG·STATUS 등) + 안내문 3줄 — 카피 원칙(자기해설 금지·내부용어 금지) 위반.

## 2. 존재 이유 (설계 축)

**"글 쓰는 방"이다.** 진입 즉시, 스크롤 없이, 타이핑을 시작할 수 있어야 한다.
기능은 딱 4개만 노출한다: **쓰기 · 미리보기 · 발행 · 초안 서랍.** 나머지는 전부 접는다.

## 3. 재설계

### 3.1 레이아웃 — 단일 컬럼
- 얇은 **스튜디오 바 1줄** + 제목 입력 + 본문 에디터(뷰포트 잔여 전부).
- 역명판 헤더·통계 타일·스테퍼 **제거**. station-topbar 는 전역 규칙상 유지하되 스튜디오에서는 그 아래 크롬이 스튜디오 바 하나뿐이어야 한다.

### 3.2 스튜디오 바
- 좌: `← 나가기` + 문서 제목(비면 "새 초안").
- 우: 저장 상태 텍스트(`저장됨 HH:MM` / `저장 중…`) · `[미리보기]` 토글 · **`[발행]` — 화면 유일의 primary** · `⋯` 메뉴(초안 서랍 / 보관 / 새 초안).

### 3.3 자동저장 기본
- 수동 저장 버튼 제거. dirty 시 debounce 자동저장. 이탈 가드·전환 가드는 기존 로직(TKT-054 계열) 재사용 — 동작 변경 금지, 트리거만 자동화.

### 3.4 발행 시트
- `[발행]` → 시트(모바일 bottom sheet)에서 한 번에: **slug**(자동 생성, 수정 가능·필드 내 형식 예시로 안내) · **요약** · **태그** · 보관 여부. 확정 시 발행 후 글 상세로 이동.

### 3.5 미리보기
- 같은 자리 토글(에디터 ↔ 렌더). 분할 화면 금지 — 모바일 우선.

### 3.6 초안 서랍
- 상시 노출 제거. `⋯` 메뉴(또는 바의 서랍 아이콘)로 여는 **오버레이 드로어**. draft/archived 통합 리스트 + 상태 배지 + 복원.

### 3.7 카피
- 전 라벨 한국어. 안내문 0줄 원칙 — 설명이 필요 없는 UI 가 목표다.

## 4. 지키는 것 — 회귀 게이트 (블로커 기준)

- **TKT-097**(정적 모드 localStorage UX)과 충돌 금지 — **097 선행 후 착수.**

1. 진입 시 스크롤 0 에서 본문 타이핑 가능 (375×812 기준).

3. `npm --prefix frontend run build` + 기존 studio 관련 테스트 전부 그린.


## 6. 도구 메뉴 (PO 2026-09-13 추가 — TKT-105)

- 에디터 우측(데스크톱) / 스튜디오 바 `⋯` 옆(모바일)에 **도구 메뉴**: **사진 첨부**(업로드 계약은 TKT-053 BE 와 연계, 정적 모드에서는 localStorage 미리보기까지) · **제목 단계 h1/h2/h3**(유지) · **표 삽입 — 인라인 편집**(PO 2026-09-14 정정: 패널에서 표를 조립해 넣는 방식 **아님**). 도구 메뉴의 '표 삽입'은 트리거일 뿐 — 누르면 **본문 커서 위치에 2×2 표가 삽입**되고, 편집은 본문 안 표 위에서: 표 hover 시 오른쪽 가장자리 `+열`·아래 가장자리 `+행`, 셀 `⋯`로 행/열 삭제, Tab 으로 셀 이동. md 파이프 문법 노출 금지(저장 시 내부 변환). 도구 메뉴에는 미니 표·행/열 버튼을 두지 않는다.
- `← 나가기` 는 앱 내 뒤로가기(자동저장 후 블로그 허브로) — 브라우저 뒤로가기와 별개. 라벨은 "← 블로그"로 명시.
- 데스크톱 레이아웃: 본문 컬럼은 **중앙 정렬 max-width 720px** (r4 목업의 우측 치우침은 결함).

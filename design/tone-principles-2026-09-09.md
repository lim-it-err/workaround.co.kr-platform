# 디자인 톤 원칙 — "네모를 걷어낸다" (2026-09-09)

> 발주: PO "디자인이 너무 다 네모네모한데 톤 다 갈아엎을 수 있니? 세션이 많고 다 네모니까 이게 뭔지를 모르겠어."
> 기준 목업: `design/mockups/tone-pitch-r1.html` (구현과 분리된 가짜 HTML — PM 제작, 실제 토큰 차용)

## 진단

난해함의 원인은 색·그림이 아니라 **모든 정보가 같은 크기·같은 무게의 라운드 박스로 쌓여 있는 것.** 박스가 위계를 말하지 않으니 전부 읽어야 전부를 안다.

## 원칙 4 (전 화면 공통)

1. **박스는 조작부에만.** 버튼·입력·토글만 면(面)을 가진다. 읽는 콘텐츠는 타이포 위계 + hairline 구분선(`--line`)으로 흐른다. 통계 타일·정보 카드 그리드 금지.
2. **화면당 주인공 1.** 지금 가장 중요한 것 하나만 크게(왼쪽 3px 컬러 룰). 나머지는 시각표 한 줄 행(라벨 좌 · 값 우 · tabular-nums)으로 내려가고, 상세는 행 클릭으로 진입.
3. **노선색은 면이 아니라 선.** 배경 채우기·타일 대신 3px 룰·원형 배지·글자 포인트로만.
4. **영어 eyebrow 제거.** BEFORE BOARDING 류 섹션 간판을 없앤다 — 행이 자기 이름을 말한다. (카피 원칙 6 과 연동)
5. **동급 수평 나열 금지 — 단, 분류는 3묶음까지.** (PO 2026-09-13 "분류가 너무 많아… 확 줄였으면") 홈 목록은 **경험**(글쓰기 B · 여행 V) / **학습·놀이**(Advisor A · 미스터리 트레인 S · 발견 D · 취향 P — 미개통은 같은 묶음 안에서 흐리게) / **운영**(Work W · Runtime R, 보호 구역) 3묶음. 노선 1개 = 행 1개, 하위 진입(아카이브·스튜디오, 일일 안내·기록 등)은 행 안의 인라인 서브링크. '개통 예정' 별도 섹션 없음.
6. **홈의 주인공은 노선도 — 형태 재구성: 노선 3개(=분류) · 정류장 8개(=서비스).** (PO 2026-09-14, D-015) 경험선(B→V) / 학습·놀이선(A→S→D→P, D·P 는 연장 예정 점선) / 운영선(W→R)이 환승 홀에서 교차. 그림 규칙 유지: 라인+역 원+역명, 상태·통계 금지. **SVG 하나, 비율 둘**(데스크톱 가로형 2단·모바일 세로/압축 — 라벨 하한 11px, 미개통 역은 이름 흐리게). 노선색 3개, 서비스 문자 배지는 역 번호처럼 작게. 홈 목록 = 노선별 정류장 열거(별도 분류 헤더 없음).

- **데스크톱(≥900px) 홈은 2단** — 약도 좌 · 카테고리 목록 우. 모바일 세로 스택을 그대로 늘리지 않는다 (PO 데스크톱 캡처 피드백 2026-09-12). 구현 티켓 기준.

## 지키는 것 (PO 2026-09-11 — 톤 전환에서 버리지 않는 정체성)

- **지하철역 컨셉은 유효하다.** 톤 전환은 컨셉 폐기가 아니라 간소화다 — 역·노선·개찰의 은유, 노선색, 역명판 감각은 유지하되 표현을 가볍게.
- **스플래시 10초 "문 여는" 인트로는 남긴다.** (PO: "10초간 문여는 멘트처리는 남겨뒀으면") 진입 의식(ritual)으로서 유지. **PO 2026-09-14 정정: 스플래시는 현행 UI(배경·플랩보드 구조·split-flap 엔진 TKT-070/077)를 기준으로 유지한다 — 목업의 CSS 플립은 폐기. 바꾸는 것은 ①문구 시퀀스 3단계(WORKING AROUND→MIND THE GAP→DOORS OPENING — PO 2026-09-14 "처음 WORKAROUND 없애고 바로 WORKING AROUND") ②티커 3회 ③배지→순환선 심볼 ④군더더기(통계 타일 등) 제거.**
- **사이트 정체성 배지 = 순환선 심볼.** (PO 2026-09-14 "우리 홈페이지 자체가 한 노선이 된 거니까") 상단바·스플래시·파비콘의 'W 원형'을 **순환선 마크(단색 링 + 12시 기점 점)**로 교체 — 원형이라 지하철 단서는 유지. 노선 문자 배지(B·V·S…)는 환승역/노선용으로 그대로.
- **지하철 원형 번호 배지는 메인에서 유지.** (PO: "초반 메인에 지하철 숫자 형태는 여전히 유효해야 — 지하철 컨셉이라는 걸 알기 위해서는") 상단 바의 원형 배지와 노선도·카테고리 행의 노선 문자 배지(B·V·S…)는 지하철 노선 번호 형태를 지킨다 — 첫 화면에서 컨셉을 알리는 최소 단서다.
- **split-flap 플랩 보드는 선택.** (PO: "가능하면 [유지], 없애도 됨") 새 톤과 무게가 안 맞으면 단순한 전환 연출로 대체 가능 — 구현 티켓에서 판단.

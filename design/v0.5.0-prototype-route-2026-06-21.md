# UI-v0.5.0 프로토타입 레일

작성일: 2026-06-21  
작성자: designer

## 목적

이 문서는 `UI-v0.4.0` 실사용 포털을 유지한 채, `UI-v0.5.0` 가상 화면을 어디서 어떻게 검토할지 정리하는 기준선이다.

핵심은 아래 두 가지다.

1. 실사용 경로 `/` 를 덮어쓰지 않는다.
2. 다음 버전 시안은 기존 `/test` 와도 섞지 않고 `/test/v0-5-0` 아래에 따로 둔다.

## 현재 상태 확인

2026-06-21 로컬 프리뷰 재확인 기준:

- `http://127.0.0.1:7000/` 응답 `200`
- `http://127.0.0.1:7000/test` 응답 `200`
- `http://127.0.0.1:8080/api/health` 응답 `200`
- `http://127.0.0.1:8003/health` 응답 `200`

즉 `v0.4.0` 포털 구조는 현재 로컬에서 아래처럼 읽힌다.

- `/`: 실제 API 연결 포털
- `/test`: 기존 검수 더미 레일
- `v0.5.0`: 아직 실사용이 아니라 별도 프로토타입 레일이 필요

## 이번 버전에서 바꾸는 UX 방향

### 1. 메인 허브는 계속 라우터여야 한다

- `v0.4.0` 에서 복구한 `Main Junction` 원칙을 유지한다.
- `v0.5.0` 도 메인에서 기능을 직접 수행하지 않는다.
- 새 기능은 허브에서 한 단계 더 들어간 승강장으로 본다.

### 2. 택시 시뮬레이터는 표보다 구역 감각이 먼저 읽혀야 한다

- 사용자는 "어느 구역에 요청이 몰리는지" 를 먼저 봐야 한다.
- 그 다음에 차량 상태와 리워드가 이어져야 한다.
- 즉 진입 순서는 `구역 -> 요청 -> 차량 -> 리워드` 다.

### 3. Work Manager 후속 확장은 기존 보드에 바로 섞지 않는다

- worker 가시화
- 우선순위 반응
- 저장 계층 전환 준비

위 세 가지는 `Crew Board` 같은 별도 승강장으로 먼저 검토한다.

### 4. 실사용과 가상 레일은 항상 분리한다

- `/` 는 live
- `/test` 는 `v0.4.0` 검수
- `/test/v0-5-0` 는 `v0.5.0` 디자인 프로토타입

이 경계는 오케스트레이터가 티켓을 만들 때도 그대로 유지한다.

## 화면 구성

### 1. Junction

역할:

- `v0.5.0` 에서 무엇이 새로 열리는지 요약
- 새 승강장으로 이동
- 오케스트레이터가 구현 슬라이스를 빠르게 나누도록 도움

보여줄 것:

- Taxi District Lab
- Crew Board
- Signal Room
- 모바일 재배치 순서

보여주지 않을 것:

- 실사용 포털용 상세 보드 직접 노출
- 택시 시뮬레이터 전체 표를 메인에 그대로 펼치는 것

### 2. Taxi District Lab

역할:

- `v0.5.0` 핵심 시뮬레이터 화면

보여줄 것:

- 구역 메쉬
- 요청 수
- 차량 상태 카드
- 리워드/패널티
- 요청 -> 배차 -> 점수 흐름

디자인 포인트:

- 서울 지하철 환승 허브의 시각 질서를 유지하되, 정보 구조는 "지도형 시뮬레이터" 처럼 읽혀야 한다.

### 3. Crew Board

역할:

- worker 가시화와 운영 반응 설계

보여줄 것:

- 어떤 worker 가 무엇을 잡았는지
- 어떤 버전 레일을 보고 있는지
- 우선순위가 어떻게 시각 반응으로 이어지는지

### 4. Signal Room

역할:

- 실사용 경로와 가상 경로의 분리 규칙을 고정
- 오케스트레이터 검수 위치를 한 화면에서 안내

## 모바일 원칙

- 모바일은 축소판이 아니라 재배치다.
- 순서는 `허브 카드 -> 구역 지도 -> 차량 카드 -> 운영 설명` 이다.
- 작은 화면에서는 한 줄에 많은 판단을 넣지 않고 카드 리듬을 우선한다.

## 오케스트레이터 티켓 슬라이스 제안

1. `Hub Shell v0.5.0`
   - `/test/v0-5-0/junction`
   - 허브 카드, 진입 라벨, 모바일 재배치

2. `Taxi Simulator Core UX`
   - `/test/v0-5-0/taxi`
   - 구역 메쉬, 차량 카드, 리워드 보드

3. `Crew Visibility UX`
   - `/test/v0-5-0/ops`
   - worker 카드, 우선순위 반응, 운영 메타 패널

4. `Signal Separation UX`
   - `/test/v0-5-0/signals`
   - live/prototype 분리 규칙, 검수 경로, handoff 문구

## 구현 가드레일

- `v0.5.0` 디자인 검수는 기존 `/test?view=...` 를 덮어쓰지 않는다.
- 실사용 `/` 에는 새 가상 카드나 임시 리워드 더미를 섞지 않는다.
- 디자인 변경점은 먼저 `design/orchestrator_review/` 에 append 하고, 합의 후 `review_done/` 으로 이동한다.

## 버전 히스토리 메모

- 현재 디자인 히스토리 태그: `UI-v0.5.0`
- 직전 기준선: `UI-v0.4.0`
- 차이:
  - 기존 `/test` 검수 유지
  - 새 `/test/v0-5-0` 가상 레일 추가
  - 택시 시뮬레이터 중심의 새 승강장 구조 시작

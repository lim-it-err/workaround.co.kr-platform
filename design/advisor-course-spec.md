## 1. 코스 컨테이너 (TKT-124 `[FE]`)
- `courses[]` — `id · title · subtitle · theme(도메인) · missions[missionId] · origin{line:'V', tripId, stopIds[]}(선택 — 환승 출처)`. 코스는 A 노선의 정류장; 미션은 코스 안의 항목.
- 기존 미션(33+6)은 "기본 코스"로 묶여 회귀 0. 코스 목록 화면 = 시각표 행(원칙 5), 코스 안은 미션 행 + 형식 배지(**코딩 / 게임 / 시뮬**).
- 미션 형식 3종 정의: **코딩 미션** = 코드 제출(FileSubmitEditor)→리뷰(ReviewPage) / **게임** = swipe·probe·boundary·practice / **시뮬** = 격납고 엔진 재사용(택시 디스패치 등).

## 3. 환승 (TKT-125 `[FE]`) — 경험(V) ↔ 배움(A)
- **V→A**: 여정 노선도·일차 시각표의 정차역(벨베데레·쇤부른·할슈타트 등)에 `이걸로 미션 만들기 →` 링크 → 해당 코스/미션 딥링크(`/advisor/#/courses/vienna-1900/...`). 데이터: 정차역 `missions[]`(코스·미션 id).
- **A→V**: 미션 카드에 `이 미션의 정류장 ←` (여행·일차·정차역 딥링크). 여행이 없으면 숨김.
- 표현: 시각표 행 우측 한 마디 + 환승 아이콘(순환선 심볼 소형) — 원칙 3(면 없이 배지·글자).

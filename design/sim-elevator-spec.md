# 엘리베이터 승강장 재설계 스펙 (TKT-083 · [SIM] 구현용)

근거: PO "아무것도 안 해, 표현 방식부터 원점 재검토" / R1 승인 (2026-08-18). 도메인 계약(사람 단위·연속 위치·워프 금지)은 불변. 이 문서만 보고 추측 없이 구현 가능해야 한다.

## 0. 존재 이유 재정의

이 화면의 제품은 조작판이 아니라 **"살아 움직이는 건물 단면"**이다. 방치해도 볼거리가 있고, 개입하면 반응이 즉시 보인다. 판정 기준: **아무것도 안 눌러도 30초 안에 화면에서 3가지 이상의 변화가 보인다.**

## 1. 레이아웃 (데스크톱 기준, 모바일은 §5)

```
┌ StationHeader (E01, 기존 유지) ─────────────────────────┐
├──────────────────┬──────────────────────────────────┤
│  수직 단면 뷰       │  우측 패널                          │
│  (화면의 70%)      │  ① 지표 스트립 (대기/탑승/이동중)      │
│                  │  ② 수요 프리셋 (한산/보통/혼잡 3버튼)   │
│                  │  ③ 이벤트 티커 (최근 8건)             │
└──────────────────┴──────────────────────────────────┘
```

## 2. 수직 단면 뷰 (핵심 — 신규 컴포넌트 `ElevatorCrossSection.vue`)

- **구조**: 좌측 층 눈금(23F~1F, 4~5층 간격 라벨) + car 수만큼의 샤프트 열(기본 4열) + 각 층 좌측에 대기 인원 표시.
- **car**: 세로 트랙 위의 둥근 사각형. `top = (23 - position) / 22 * 100%` — position 은 기존 코어의 **연속 위치 값을 그대로** 사용(보간은 CSS transition 금지, 코어 틱 기반 — 워프 금지 계약). car 내부에 탑승 인원 숫자(`.num`), 상단에 방향 화살표(▲▼, idle 은 없음).
- **대기 인원**: 층별로 점 도트(1인 = 1도트, 6인 초과 시 `5+n` 숫자). 승객이 타면 도트가 car 쪽으로 흡수되는 마이크로 애니메이션(80ms, reduced-motion 시 즉시).
- **색**: 노선색 `--line-e` 는 car 와 진행 트랙에만. 대기 도트는 `--text-2`, 혼잡 층(대기 8+)만 `--safety`. 액센트 절제 원칙 유지.
- **자동 수요**: 화면 진입 시 수요 루프가 항상 가동(기존 프리셋 '보통'). 정지 버튼 없음 — 시뮬레이터는 꺼지지 않는다. step 버튼 폐기.

## 3. 우측 패널

1. **지표 스트립**: 대기 / 탑승 / 이동 중 car / 평균 대기(초) — `.num`, 큰 숫자. 배지·설명문 금지.
2. **수요 프리셋**: `한산·보통·혼잡` 3개 칩 버튼(현재 선택 강조 = `--line-e`). 기존 슬라이더 2개(수요 강도·car 수)는 "고급" 접힘 아래로 이동 — 첫 화면에서 숨김.
3. **이벤트 티커**: "14F 3명 탑승 → E2", "E1 21F 도착" 형식 한 줄 로그 최근 8건, 새 항목이 위로. 텍스트는 15자 내외.

## 4. 삭제 목록 (원점 재검토의 실질)

- 기존 `car-row` 목록형 상태 표(단면 뷰가 대체), step/reset 디버그 버튼(고급 접힘으로), 상행/하행 1명 추가 버튼(층 눈금 클릭으로 대체 — 층 클릭 시 그 층에 대기 1인 추가, 클릭 피드백은 도트 생성), 설명 문단 전부(카피 원칙).

## 5. 모바일 (≤760px)

단면 뷰가 1급: 전체 폭 사용, 높이 60vh. 우측 패널은 아래로 — 지표 스트립(가로 랩) → 프리셋 → 티커(접힘 기본). 층 눈금 라벨은 6층 간격으로 축소.

## 6. 완료 게이트 ([SIM] 티켓 공통 + 추가)

- `npm run build` · 다크/라이트 · 모바일 375px 오버플로 0
- **방치 30초 캡처**: 자동 수요로 car 이동·도트 증감·티커 갱신이 보이는 것을 기록
- 층 클릭 → 대기 도트 즉시 생성 → 근접 car 반응 확인
- 코어 로직(사람 단위 모델) 무변경 — 표시층만 재구성. 기존 코어 함수 시그니처 변경 금지

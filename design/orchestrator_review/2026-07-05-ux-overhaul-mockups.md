## 시안 요약

### 시안 A · 서울 사인 정제

- 현행 다크 사인 시스템의 정제판. Base Metal/Panel Surface + Safety Yellow/Exit Green 을 유지하되 그라디언트·장식 소음을 제거하고 위계와 여백을 강화.
- 노랑은 현재 위치·포커스·섹션 레일에만, 초록은 진입(way out) CTA 에만 쓰는 절제 규칙을 시연.
- 승강장 헤더를 실제 역명판 문법(노선색 띠 + 역 코드 + 인접역 화살표)으로 통일.

### 시안 B · 종이 아카이브

- 블로그 중심 정체성을 가장 강하게 반영. 기록 보관함/잡지 무드(명조 표제, 점선 리더 목차, 서지 목록형 아카이브)에 지하철 사인은 액센트(노선 칩, 승강장 띠)로 물러남.
- 환승 홀이 "표지 + 목차" 가 되고 시뮬레이터는 "부록 색인" 으로 정렬되어 본선/놀이터 위계가 가장 뚜렷.
- 플랩 보드도 레터프레스 재질(크림 판/호두나무 판)로 번역해 콘셉트 일관성 유지.

### 시안 C · 야간 노선도

- 환승 홀을 문자 그대로의 SVG 노선도로 그림: 블로그가 굵은 본선(아카이브—글 상세—스튜디오 종점), 시뮬레이터 4종이 가는 지선.
- 카드 대신 행 목록과 하어라인, 순흑 배경과 고대비 타이포. Safety Yellow 는 오직 현재 위치 마커에만.
- 모바일에서는 노선도가 객차 내 세로 노선띠로 재배치되어 "축소가 아니라 재배치" 원칙을 가장 직관적으로 시연.

## 플랩(행선판) 개선 공통 사양

- 구조: 셀당 4장(고정 위/아래 판 + 회전 플랩 2장). 위 플랩은 현재 글자를 안고 `rotateX(0 → -90deg)` ease-in 낙하, 아래 플랩은 다음 글자를 안고 `rotateX(90deg → 0)` ease-out 착지.
- 마지막 장은 반동 정착 keyframes(0 → +10.5deg → -2.5deg → 0)로 기계식 손맛을 부여.
- 셀마다 중간 글자 3~9장을 넘기고, 열 단위 시차(행 150~190ms + 열 48~62ms + 지터)로 도착 리듬을 만든다.
- 글자 종류별 문자판(라틴/숫자/한글) 분리, `prefers-reduced-motion` 시 결과만 표시, `다시 재생` 버튼 제공.
- 현행 구현(1회성 rotateX 등장 + blur)과 달리 실제 "넘어가는" 연출이므로, 구현 시 이 목업의 CSS/JS 를 레퍼런스로 사용 가능.

## 열린 질문 (사용자 확인 필요)

1. 방향 선택: A / B / C 단일 채택인가, 조합(예: 골격 A + 블로그 구간 B, 또는 환승 홀만 C 방식)인가?
2. 웹폰트: 현재 시스템 폰트 스택(설치된 경우에만 Pretendard). 자체 호스팅 Pretendard 도입을 허용할지? (외부 CDN 없이 번들 가능, 용량 증가)
3. Line T(택시) 색: 금색 계열(현행)을 유지했는데, 3호선 주황으로 바꿀지?
4. 스플래시 유지 시간: 현행 10초 자동 전환을 유지할지, 플랩 완주(~3초) 후 즉시 전환 가능하게 줄일지?
5. 시안 C 채택 시 SVG 노선도는 기능 추가마다 좌표 갱신 비용이 있다. 수용 가능한지? (컴포넌트화로 완화 가능)
6. 다크/라이트 기본값: 시안별 기본 무드가 다른데, 최종 채택 시 사이트 기본 테마를 무엇으로 할지?
